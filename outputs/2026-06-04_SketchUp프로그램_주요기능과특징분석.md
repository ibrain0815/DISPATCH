## 1. SketchUp 개요

### 1.1 정의 및 특징

```
SketchUp (스케치업)이란?

정의:
"3D로 생각하고, 3D로 드로잉하는" 직관적인 3D 모델링 소프트웨어

개발사: Trimble Inc. (미국)
초기 개발: Google (2000년대 → 2012년 Trimble 인수)

핵심 철학:
"누구나 쉽게 3D를 모델링할 수 있게"
→ 전문가 수준의 기능 + 초보자 친화적 인터페이스
```

### 1.2 주요 특징

```
1️⃣ 직관적인 인터페이스
   • Push/Pull 기능: 2D 도형을 쉽게 3D로 변환
   • 마우스로 드래그만으로 모델링 가능
   • 초보자도 30분 내에 기본 조작 가능

2️⃣ 빠른 모델링 속도
   • 복잡한 건축물도 몇 시간 내 완성
   • 다른 CAD(AutoCAD, Revit)보다 3~5배 빠름
   • 스케치에서 완성도까지 신속

3️⃣ 강력한 시각화
   • 포토리얼한 렌더링 가능
   • 재료, 질감, 조명 세밀 조정
   • 프레젠테이션용 고품질 이미지 생성

4️⃣ 대규모 커뮤니티
   • 100만+ 전 세계 사용자
   • 무료 모델 400만+ 개 (3D Warehouse)
   • 확장 기능 600+개 (Extension Warehouse)

5️⃣ 클라우드 협업
   • 팀 프로젝트 실시간 공유 가능
   • 어디서나 웹 접속으로 작업 가능
   • iPad에서도 모델링 가능
```

### 1.3 사용 분야

```
【건축 및 도시설계】
• 건물 설계 (주택, 상업시설)
• 도시 계획 및 마스터플랜
• 조경 설계
• 도시재생 프로젝트

【인테리어 디자인】
• 실내공간 설계
• 가구 배치 및 선정
• 색상/재질 시뮬레이션
• 3D 시각화 프레젠테이션

【제품 디자인】
• 소품 디자인
• 가구 설계
• 기계 부품 모델링

【건설 및 시공】
• 현장 조건 검토
• 간섭 확인 (Clash Detection)
• 공정 계획 시각화

【교육 및 취미】
• 건축 교육 및 학습
• 취미 설계 (정원, 집 리모델링)
• 게임 맵 설계
• 3D 프린팅 모델 제작
```

## 2. 핵심 기능

### 2.1 기본 모델링 도구

```
【Push/Pull (밀기/당기기) - 핵심 기능】

개념:
2D 도형을 선택한 후 마우스로 드래그하면
자동으로 3D 입체로 변환

사용 예시:
□ 정사각형 → 직육면체
□ 육각형 → 육각기둥
□ 원형 → 원기둥/구

장점:
• CAD보다 직관적
• 복잡한 명령어 불필요
• 시각적 피드백 즉시 확인

난이도: ★ (매우 쉬움)
```

```
【선 및 도형 그리기】

기본 도구:
• Line (직선): 자유로운 선 그리기
• Rectangle (직사각형): 정확한 좌표 입력 가능
• Circle (원): 반지름 지정 가능
• Arc (호): 자연스러운 곡선
• Polygon (다각형): 정다각형

특징:
• 단위 자동 인식 (m, cm, inch 등)
• 치수 실시간 표시
• 스냅(Snap) 기능으로 정확한 배치

예시:
"5m 거리 직선 그으려면?"
→ Line 도구 선택 → 거리 입력: 5m → Enter
→ 정확하게 5m 직선 완성
```

```
【Move & Copy (이동 및 복사)】

기능:
• 객체 선택 후 원하는 위치로 이동
• 복사하면서 이동 가능
• 배열(Array) 기능으로 반복 배치

활용:
• 기둥 원형 배치
• 창/문 동일 간격 배치
• 가구 반복 배치

예시:
"기둥 10개를 3m 간격으로 배치"
→ 1개 기둥 그리기
→ Copy 선택 → 개수와 간격 지정
→ 일괄 배치 완성
```

```
【Rotate (회전)】

기능:
• 객체 중심축 기준 회전
• 정확한 각도 지정 가능
• 3축(X, Y, Z) 각 방향 회전

활용:
• 건물 배치 회전
• 카메라 각도 조정
• 가구 방향 변경

예시:
"건물을 45도 회전"
→ Rotate 도구 선택
→ 회전축 중심 지정
→ 각도 입력: 45도 → Enter
```

```
【Scale (축소/확대)】

기능:
• 균등 축소/확대
• 선택축 기준 비균등 확대
• 배수 또는 백분율 지정

활용:
• 모델 크기 조정
• 참조 이미지 맞춤
• 일괄 축소/확대

예시:
"모델을 2배 확대"
→ Scale 선택 → 2 입력 → Enter
```

### 2.2 고급 모델링 기능

```
【Follow Me (추종)】

개념:
2D 도형을 경로(Path)를 따라 이동시키면서 3D 형태 생성

활용:
• 난간, 계단 모델링
• 곡선 구조물 생성
• 복잡한 곡면 표현

예시:
"곡선 난간 만들기"
→ 난간 단면 도형 그리기
→ 난간이 지나갈 곡선 경로 그리기
→ Follow Me로 자동 생성
```

```
【Component & Group】

Component (컴포넌트):
• 반복되는 요소 저장 (기둥, 창, 문)
• 수정하면 모든 복사본에 자동 반영
• 용량 절감, 관리 효율화

Group (그룹):
• 여러 객체를 하나로 묶기
• 움직일 때 함께 움직임
• Component보다 단순

활용:
• 건물 설계에서 기둥 100개 배치
  → 1개 만들고 99번 복사
  → 나중에 1개만 수정하면 100개 모두 변경
```

```
【3D Warehouse 통합】

기능:
• 400만+ 기성 모델 활용
• 가구, 식물, 자동차, 인물 등
• 검색으로 즉시 삽입

활용:
• 처음부터 만들지 않고 완성된 모델 활용
• 시간 절감 (80% 이상)
• 프레젠테이션 퀄리티 향상

예시:
"IKEA 소파 추가하기"
→ 3D Warehouse 검색
→ "IKEA Sofa" 검색
→ 모델 선택 → 인서트
→ 크기/회전 조정
```

### 2.3 렌더링 및 시각화

```
【재료 및 색상 지정】

기능:
• 미리 준비된 재료 라이브러리
• 목재, 벽돌, 유리, 금속 등
• 맞춤 색상 RGB 값으로 조정

적용:
□ 재료 지정 → 객체 선택 → 재료 드래그
□ 페인트버킷 도구로 색칠

Pro 기능:
"Photoreal Materials" (고품질 사진 소재)
• 실사 이미지 기반 재료
• 반사, 투명도, 범프맵 지원
• 포토리얼한 렌더링 가능
```

```
【조명 설정】

기능:
• 태양광: 지구상 위치/시간 자동 계산
• 실내 조명: 인공 조명원 배치
• 그림자: 명암 표현

활용:
• 일조 분석
• 야간 장면 표현
• 분위기 연출

예시:
"건물의 여름/겨울 일조 비교"
→ 위치/날짜 지정
→ 그림자 시뮬레이션
→ 시간대별 변화 관찰
```

```
【Camera & Animation (카메라 및 애니메이션)】

카메라 기능:
• 보기 각도 자유 조정
• 투시도, 등각도 지정
• 워크스루 (카메라 이동 경로)

애니메이션:
• 카메라 경로 자동 생성
• 비디오로 내보내기 (mp4, avi)
• 프레젠테이션용 동영상 제작

예시:
"건축물 둘러보기 영상 만들기"
→ 카메라 경로 설정
→ 이동 속도 조정
→ 동영상 렌더링
→ 클라이언트에게 제시
```

### 2.4 문서화 및 출력

```
【LayOut (레이아웃)】

Pro 버전의 2D 도면 작성 도구:

기능:
• SketchUp 3D 모델 → 2D 도면 변환
• 도면 레이어 관리
• 치수, 주석, 텍스트 추가
• 건축 설계도, 시공도 작성

장점:
• Revit의 "시트" 개념과 유사
• 3D에서 변경하면 도면 자동 업데이트
• PDF로 내보내기 (출력용)

활용:
"제출용 도면 패키지 작성"
→ SketchUp 3D 모델
→ LayOut에서 도면 뽑기
→ 치수, 설명 추가
→ PDF 저장 및 출력
```

```
【Sections (단면도)】

기능:
• 3D 모델에서 자동 단면도 추출
• 평면도, 입면도, 단면도 생성

활용:
• 건축도면 작성
• 기계부품 상세 표현
• 투시도와 함께 제시

장점:
• 수동 그리기 필요 없음
• 모델 변경 시 자동 업데이트
```

## 4. SketchUp 버전 비교

### 4.1 무료 vs Pro 비교

```
┌─────────────────────────────────────────┐
│          기능          │  무료  │  Pro

│ Push/Pull 도구        │  ✅   │  ✅
│ 3D Warehouse 접근     │  ✅   │  ✅
│ 
│ 2D 도면작성(LayOut)   │  ❌   │  ✅
│ Photoreal Materials   │  ❌   │  ✅
│ 고급 렌더링          │  ❌   │  ✅
│ 클라우드 저장(Pro)    │  1GB  │ 무제한

```

### 4.2 가격 및 라이선스

```
【SketchUp Free】
비용: 무료
용도: 개인 학습, 취미
주의: 상업적 사용 불가

【SketchUp Free (웹)】
비용: 무료
기능: 웹 브라우저에서 사용
장점: 설치 불필요, 어디서나 접근

## 7. 초보자 기초 가이드

### 7.1 SketchUp 시작하기

```
【Step 1: 다운로드 및 설치】

무료 버전 시작:
1. https://sketchup.trimble.com/en 방문
2. "Start a Trial" 또는 "Get Started" 클릭
3. 계정 생성 (Google/Email)
4. 무료 버전 선택
5. 설치 또는 웹 브라우저 시작

소요 시간: 10분

【Step 2: 기본 인터페이스 이해】

주요 구성:
┌──────────────────────────┐
│ 메뉴바                   │
├──────────────────────────┤
│ 도구 모음                │
├──────────────────────────┤
│         캔버스 (작업 공간)   │
│      (마우스로 모델링)    │
├──────────────────────────┤
│ 라이브러리 (오른쪽)      │
│ - Inspector (속성)       │
│ - 3D Warehouse           │
└──────────────────────────┘

핵심 도구:
1. Selection (선택) - 마우스 포인터
2. Push/Pull (밀기/당기기) - 2D→3D 변환
3. Line (직선) - 선 그리기
4. Rectangle (직사각형) - 도형 그리기
5. Move (이동) - 객체 이동
6. Rotate (회전) - 객체 회전
```

```
【Step 3: 첫 모델링 - 간단한 집 만들기】

목표: 단순한 집(큐브 지붕)을 30분 내 완성

시간별 진행:

0~5분: 기초 그리기
□ Rectangle 도구 선택
□ 캔버스에 "10m" 입력
□ Tab → "8m" 입력 → Enter
□ 10m × 8m 직사각형 완성

5~10분: 벽 높이 만들기
□ Push/Pull 도구 선택
□ 직사각형 클릭
□ 마우스 드래그
□ "3m" 입력 → Enter
□ 높이 3m 벽 완성

10~15분: 지붕 만들기
□ Line 도구로 지붕 삼각형 그리기
□ Push/Pull로 지붕 높이 추가 (1m)

15~20분: 색상 지정
□ 재료(Paint) 도구 선택
□ 색상 선택 (외벽용 회색)
□ 벽 클릭 → 색상 지정
□ 지붕은 적색으로 변경

20~30분: 창/문 추가
□ 3D Warehouse에서 "window" 검색
□ 창 모델 선택 → 삽입
□ 크기 조정
□ 복사해서 여러 위치에 배치
□ 문도 마찬가지

30분: 완성
"초보자도 첫 모델 완성 가능!"
```

### 7.2 초보자가 자주 하는 실수

```
❌ 실수 1: 복잡한 모델부터 시작

"사전 계획 수립"
