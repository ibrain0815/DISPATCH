## 💡 2. ETF의 기본 개념

### 2.1 ETF란 무엇인가?

```
ETF = Exchange Traded Fund (상장지수펀드)

쉽게 말하면:
"여러 주식을 한데 묶은 상품을 주식처럼 사는 것"

비유:
┌─────────────────────────────────────┐
│ 도시락을 생각해보세요             │
├─────────────────────────────────────┤
│ 밥 + 계란말이 + 야채반찬            │
│ = 여러 가지가 들어있는 도시락        │
└─────────────────────────────────────┘

ETF도 마찬가지:
주식 여러 개 + 채권 일부 = 한 상품으로 판매
```

### 2.2 펀드와의 차이점

```
펀드 vs ETF

펀드:
- 펀드매니저가 관리
- 느린 체결 (다음날)
- 환매 수수료
- 투명성 낮음 (매일 공개 X)

ETF:
- 자동 따라감 (지수)
- 빠른 체결 (실시간)
- 낮은 수수료
- 투명성 높음 (실시간 공개)

결론: "ETF가 더 저렴하고 투명"
```

### 2.3 주식과의 차이점

```
주식 vs ETF

주식:
- 1개 회사에 투자
- 위험 높음 (집중)
- 수익 높을 수 있음
- 변동성 큼

ETF:
- 여러 회사/자산에 투자
- 위험 낮음 (분산)
- 안정적 수익
- 변동성 작음

결론: "ETF는 더 안전한 투자"
```

### 2.4 왜 ETF가 인기인가?

```
1. 낮은 진입 금액 (1주부터 가능, 보통 3~5만원)
2. 자동 분산 투자 (여러 주식 한 번에)
3. 낮은 수수료 (펀드보다 10배 저렴)
4. 높은 투명성 (지수 공개)
5. 실시간 거래 (언제든 사고팔기 가능)
6. 세제 혜택 (배당소득세 낮음)
```

## 👤 8. 개인투자자 관점

### 8.1 ETF 투자의 장점

```
✓ 낮은 진입 금액 (1~5만원)
✓ 자동 분산 투자
✓ 낮은 수수료 (0.1% ~ 0.3%)
✓ 높은 투명성
✓ 실시간 거래
✓ 세제 혜택 (배당소득세 낮음)
✓ 감정적 판단 최소화
```

### 8.2 ETF 투자의 단점

```
✗ 개별주처럼 급등 기회 적음
✗ 개별 기업 분석 불필요 (즉, 깊이 없음)
✗ 시장 전체 하락 시 같이 하락
✗ 선택 폭이 많아서 고민 필요
```

### 8.4 투자 전략

#### 분할 매수 (드라이 에버리징)

```
개념: "한 번에 다 사지 말고, 나눠 사라"

예시:
5,000만원을 투자한다면:
├─ 월 1,000만원씩 5개월에 걸쳐 매수
│  또는
├─ 주 200만원씩 25주에 걸쳐 매수

효과:
✓ 고점 매수 위험 감소
✓ 평균 매수가 낮춤
✓ 심리적 안정감

결과: 10년 수익률 +94% vs +6.87%
      = 전략으로 약 10배 차이 가능!
```

#### 포트폴리오 구성

