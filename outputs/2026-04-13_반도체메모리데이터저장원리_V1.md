# 반도체 메모리의 데이터 저장 원리

## 🔍 메모리란?

**메모리** = 전자 데이터를 저장하는 장치

```
비유:
종이 노트북: 펜으로 쓴 글씨를 저장
            지우려면 지우개로 긁어야 함
            
메모리: 전기 신호로 데이터 저장
       전기 신호를 켜고 끄는 것으로 저장/삭제
       훨씬 빠르고 많은 양 저장 가능
```

### 메모리의 두 가지 개념

```
1. 저장 용량 (Storage)
   - 사진, 영상, 문서 저장
   - SSD, HDD (하드 드라이브)
   - 전원 꺼져도 유지 (비휘발성)

2. 작업 메모리 (Working Memory)
   - CPU가 현재 작업하는 데이터
   - RAM
   - 전원 켜져있을 때만 유지 (휘발성)
```

## ⚡ 메모리의 기본 단위: 비트와 바이트

### 비트(Bit) - 최소 단위

```
Bit = Binary Digit (이진 숫자)

상태 2가지만 가능:
• 1 (ON, 전기 흐름, 전기 신호 있음)
• 0 (OFF, 전기 흐름 없음, 전기 신호 없음)

물리적 의미:
• 1 = 전하 충전 (트랜지스터가 켜짐)
• 0 = 전하 방전 (트랜지스터가 꺼짐)
```

### 바이트(Byte) - 실용 단위

```
1 Byte = 8 Bit

예: 01101010 (이진수)
    = 106 (10진수)
    = "j" (문자)

모든 데이터는 바이트 단위로 저장:
• 1 바이트: 영문자 1개
• 1 킬로바이트(KB): 1,000 바이트 = 문서 1장
• 1 메가바이트(MB): 1,000,000 바이트 = 사진 1장
• 1 기가바이트(GB): 10억 바이트 = 영화 2시간
```

## 🏗️ 메모리를 만드는 기본 부품: 트랜지스터

### 트랜지스터란?

```
전자 스위치 역할
   ↓
매우 빠르고 작음 (나노 수준)
   ↓
현대 반도체 메모리의 기초

구조 (간단히):
전원
  ↓
[게이트]← 제어 신호 (1 또는 0)
  ↓
[소스]←→ [드레인] (전류 통로)

작동:
게이트에 신호 1 입력 → 전류 흐름 (ON)
게이트에 신호 0 입력 → 전류 차단 (OFF)
```

### 트랜지스터의 규모

```
1960년대: 트랜지스터 1개 크기 = 손가락 마디
1990년대: 0.5 마이크로미터 (머리카락의 1/100)
2010년대: 7나노미터 (DNA의 1/20)
2024년: 3나노미터 (원자 수십 개 크기!)

현재 칩 한 개:
- 크기: 손톱만함
- 트랜지스터 개수: 1,000억 개 (iPhone 같은 스마트폰)
- 처리 속도: 나노초 단위 (10억분의 1초)
```

## 💾 RAM (Random Access Memory) - 작업 메모리

### 특징

```
역할: CPU가 현재 작업하는 데이터 임시 저장
특성:
- 매우 빠름 (나노초 단위)
- 용량은 작음 (GB 수준)
- 전원 꺼지면 데이터 사라짐 (휘발성)
- 비용 낮음 (용도 대비)

용도:
- 브라우저 탭 열기
- 게임 플레이
- 영상 편집
- 프로그램 실행
```

### DRAM (Dynamic RAM) - 가장 흔한 RAM

#### 원리

```
기본 구조: 트랜지스터 1개 + 커패시터 1개

커패시터란?
   → 전하(전기) 저장 용기
   → 마치 배터리처럼
   → 하지만 매우 작은 규모

작동:
비트 1 저장:
  ① 트랜지스터 켜기 (제어 신호 1)
  ② 커패시터에 전하 충전
  ③ "1"로 저장됨

비트 0 저장:
  ① 트랜지스터 켜기
  ② 커패시터 방전
  ③ "0"으로 저장됨

데이터 읽기:
  ① 트랜지스터 켜기
  ② 커패시터의 전하 수준 측정
  ③ 높음 → "1", 낮음 → "0"
```

#### DRAM의 문제: 데이터 소멸

```
문제점:
커패시터는 천천히 방전됨
   ↓
저장된 전하가 점차 줄어듦
   ↓
시간이 지나면 데이터 사라짐 (수 밀리초)

해결책: 주기적 새로고침 (Refresh)
   ↓
CPU가 자동으로 주기적 확인
   ↓
전하 약해지면 다시 충전
   ↓
데이터 유지

특징:
- 이름의 유래: "Dynamic" (동적)
- 계속 움직여야 데이터 유지
- 매우 빠르지만 전력 소비 많음
```

#### DRAM의 용량 구성

```
DRAM 칩 1개 구조:
┌─────────────────────────┐
│  8GB DRAM 칩            │
│ (약 640억 개 비트)      │
│                         │
│ 각 비트별 구조:         │
│ [트랜지스터]            │
│ [커패시터]              │
│ × 640억 개!             │
│                         │
└─────────────────────────┘

현대 PC/스마트폰:
- 8GB RAM = 8 × 10⁹ × 8 bit
         = 64 × 10⁹ bit
         = 640억 개 비트/0 저장
```

### SRAM (Static RAM) - 고급 RAM

#### 원리

```
기본 구조: 트랜지스터 6개 (복잡함)

플립플롭 회로:
  트랜지스터 2개가 서로 피드백
  ↓
  한 상태를 계속 유지
  ↓
  전하 보충 불필요

작동:
  상태 "1" 유지:
    - 트랜지스터 A: ON
    - 트랜지스터 B: OFF
    - 자동으로 유지됨

  상태 "0" 유지:
    - 트랜지스터 A: OFF
    - 트랜지스터 B: ON
    - 자동으로 유지됨

장점:
- 새로고침 불필요
- DRAM보다 빠름
- 데이터 유지 쉬움
```

#### SRAM vs DRAM 비교

```
특성          | SRAM          | DRAM
-------------|--------------|--------
속도         | 매우 빠름     | 빠름
용량         | 작음 (MB)    | 큼 (GB)
가격         | 매우 비쌈    | 저렴
전력 소비    | 중간          | 낮음
새로고침     | 불필요        | 필요
용도         | CPU 캐시    | 메인 메모리
```

#### SRAM의 용도

```
CPU 캐시 메모리:
- L1 캐시: 수십 KB (가장 빠름)
- L2 캐시: 수백 KB
- L3 캐시: 수 MB

특징:
- 매우 작은 용량만 필요
- 극도의 속도 필요
- SRAM의 높은 가격 문제없음
- CPU 칩 내부 탑재
```

## 📦 ROM (Read Only Memory) - 읽기 전용 메모리

### 특징

```
역할: 한 번 저장되면 수정 불가능한 데이터 저장
특성:
- 전원 꺼져도 데이터 유지 (비휘발성)
- 읽기만 가능 (쓰기 불가능, 원칙적으로)
- 비용 낮음
- 데이터 크기 작음

용도:
- BIOS (컴퓨터 부팅 초기 프로그램)
- 펌웨어 (기기 기본 프로그램)
- 게임카트리지 (구형)
```

### ROM의 원리

```
기본 구조: 트랜지스터 + 고정 연결

제조 단계:
① 설계: 저장할 데이터 정함 (01101010 등)
② 제조: 각 비트위치에 연결 추가/미추가
③ 완성: 고정됨

읽기 방식:
  각 위치에 신호 주입
    ↓
  연결된 위치 → "1" (신호 통과)
  연결 안 된 위치 → "0" (신호 차단)
    ↓
  데이터 읽음
```

### ROM 종류 진화

#### 1. PROM (Programmable ROM)

```
특징:
- 제조 후 한 번만 쓰기 가능
- 고객 맞춤형 데이터 저장
- 한 번 쓰면 영구 고정

방식:
- 특수 장치로 전기 펄스 가함
- 선택한 위치의 연결 끊음
- 되돌릴 수 없음

현재: 거의 사용 안 함
```

#### 2. EPROM (Erasable PROM)

```
특징:
- 쓰기/지우기 가능
- 자외선(UV)으로 지우기

원리:
- 플로팅 게이트: 전자 가두는 부위
- 자외선 조사: 전자 방출
- 데이터 소거
- 재프로그래밍 가능

현재: 특수 분야만 사용 (거의 없음)

문제점:
- 지우려면 자외선 기구 필요
- 느림 (20분 이상)
- 비효율적
```

#### 3. EEPROM (Electrically Erasable PROM)

```
특징:
- 전기 신호로 지우기/쓰기
- EPROM보다 편함

원리:
- 플로팅 게이트 사용
- 높은 전압으로 전자 주입/방출
- 빠른 지우기 (마이크로초 단위)
- 반복 가능

현재:
- 특수 칩에만 사용
- 대부분 Flash Memory로 대체
```

## 💿 Flash Memory - 현대 저장소의 주인공

### 특징

```
역할: 대용량 영구 저장 (비휘발성)
특성:
- 전원 꺼져도 데이터 유지
- 용량 매우 큼 (GB~TB)
- 속도 중간 (나노초~마이크로초)
- 비용 저렴 (용량 대비)

용도:
- SSD (노트북, PC)
- USB 메모리
- SD 카드
- 스마트폰 저장소
- 카메라 메모리카드
```

### Flash Memory의 원리

#### 기본 구조: 플로팅 게이트

```
NAND Flash 셀 구조:

┌─────────────────────────────────────┐
│ 제어 게이트 (Control Gate)          │
│ (데이터 읽기/쓰기 신호 입력)       │
│                                     │
│ 플로팅 게이트 (Floating Gate)     │
│ (전자를 가두는 격실)               │
│                                     │
│ 산화막 (Oxide Layer)               │
│ (플로팅 게이트 주변)               │
│                                     │
│ 반도체 기판                         │
└─────────────────────────────────────┘

핵심:
플로팅 게이트 = 전자를 가두는 격실
             = 마치 쥐덫처럼
             = 높은 전압 가하면 전자 유입
             = 전기를 빼면 전자 유지 (수년)
```

#### 데이터 저장 과정

```
비트 "1" 저장:
① 높은 전압(+18V) 가함
② 전자가 플로팅 게이트로 주입
③ 전자 가득 찬 상태 = "1"

비트 "0" 저장:
① 매우 높은 전압(+20V) 가함
② 플로팅 게이트의 전자 제거 (터널링)
③ 전자 없는 상태 = "0"

데이터 유지:
- 전원 꺼짐
- 플로팅 게이트 안의 전자 그대로 유지
- 수년간 보관 가능 (5~10년)
```

#### 데이터 읽기 과정

```
과정:
① 낮은 제어 전압(2~3V) 가함
② 플로팅 게이트 전자 수 측정
③ 전자 많음 → "1"
   전자 없음 → "0"
④ 데이터 읽음

특징:
- 원래 상태 손상 안 함 (읽기만)
- 수백만 번 반복 가능
```

#### 데이터 지우기 (가장 복잡)

```
Flash Memory 단점:
개별 비트 지우기 불가능!
   ↓
블록 단위로만 지우기 가능

블록이란?
- 여러 셀 묶음 (수십~수백 K)
- NAND Flash: 64K~256K 단위
- NOR Flash: 64K 단위

지우기 과정:
① 매우 높은 음전압(-20V) 가함
② 플로팅 게이트의 모든 전자 제거
③ 블록 내 모든 셀 "0" 상태로 리셋

문제점:
- 작은 용량만 지우고 싶어도 블록 전체 지움
- 속도 느림
- SSD 성능 저하의 원인
```

### NAND Flash vs NOR Flash

```
특성          | NAND          | NOR
-------------|--------------|--------
용량         | 매우 큼 (GB)  | 작음 (MB)
속도         | 중간          | 빠름
가격         | 저렴          | 비쌈
지우기       | 블록 단위     | 개별 가능
용도         | SSD, 메모리카드| 펌웨어
액세스       | 순차 (빠름)   | 랜덤 (빠름)
```

#### NAND Flash 선택 이유

```
현대 SSD는 대부분 NAND Flash

이유:
① 용량: TB 단위 가능 (NOR은 MB 수준)
② 가격: 매우 저렴 (대용량 저장에 필수)
③ 속도: 충분히 빠름 (나노초 단위)
④ 수익성: 제조비 낮음

트레이드오프:
- 지우기 복잡하지만
- 저장 용량/가격 이점 훨씬 큼
```

### SLC, MLC, TLC, QLC - 저장 용량 vs 수명

```
기술이 진화하면서 한 셀에 여러 비트 저장:

SLC (Single Level Cell):
- 1 셀 = 1 비트 (1 또는 0)
- 수명: 100,000 사이클
- 가격: 가장 비쌈
- 용도: 고급 SSD, 엔터프라이즈

MLC (Multi Level Cell):
- 1 셀 = 2 비트 (00, 01, 10, 11)
- 수명: 10,000 사이클
- 가격: 중간
- 용도: 고급 SSD

TLC (Triple Level Cell):
- 1 셀 = 3 비트 (8가지 상태)
- 수명: 1,000 사이클
- 가격: 저렴
- 용도: 일반 SSD (현재 주류)

QLC (Quad Level Cell):
- 1 셀 = 4 비트 (16가지 상태)
- 수명: 100 사이클
- 가격: 가장 저렴
- 용도: 저가 SSD, 대용량 저장
```

#### 트레이드오프 예시

```
Samsung 970 Pro (고급 SSD):
- MLC 기술 사용
- 수명: ~10,000 사이클
- 가격: 비쌈
- 신뢰성: 높음

Samsung 870 QVO (일반 SSD):
- QLC 기술 사용
- 수명: ~100 사이클
- 가격: 저렴
- 신뢰성: 낮지만 일반 사용에는 충분

일반 사용자:
SSD 수명 = 10년 이상 (일반 사용)
   ↓
QLC 사이클 (100회)로도 충분
   ↓
가격 저렴한 QLC 선택 가능
```

## 🚀 신기술 메모리들

### ReRAM (Resistive RAM) - 저항 기반

```
원리:
- 저항이 변하는 물질 사용
- 낮은 저항 = "1"
- 높은 저항 = "0"

장점:
- 매우 빠름 (피코초)
- 저전력
- 높은 밀도

현재:
- 개발 초기 단계
- 상용화 진행 중 (2025~)
- 향후 Flash 대체 가능성
```

### FeRAM (Ferroelectric RAM) - 강유전체 기반

```
원리:
- 강유전 물질의 극성 이용
- 극성 위↑ = "1"
- 극성 아래↓ = "0"

장점:
- DRAM급 속도
- FLASH급 비휘발성 (대기)
- 저전력

현재:
- 특수 분야 (자동차, IoT)
- 대중화 안 됨
```

### MRAM (Magnetoresistive RAM) - 자성 기반

```
원리:
- 자성체의 방향 이용
- 자석 ↑ = "1"
- 자석 ↓ = "0"

장점:
- 즉각적 읽기/쓰기
- 비휘발성
- 방사능 내성

현재:
- 우주/군사용
- 일부 IoT 기기
- 대중화 아직
```

## 🔄 메모리 계층 구조 (메모리 피라미드)

### 메모리 성능 vs 용량 트레이드오프

```
속도(빠름)
    ↑
    │
    │  [CPU 레지스터]          ← 나노초 / 1KB
    │       ↓
    │  [L1 캐시 (SRAM)]        ← 나노초 / 수십KB
    │       ↓
    │  [L2 캐시 (SRAM)]        ← 나노초 / 수백KB
    │       ↓
    │  [L3 캐시 (SRAM)]        ← 나노초 / 수MB
    │       ↓
    │  [RAM (DRAM)]            ← 마이크로초 / GB
    │       ↓
    │  [SSD (Flash)]           ← 마이크로초 / TB
    │       ↓
    │  [HDD (자기)]            ← 밀리초 / PB
    │
    └──────────────────────── 용량(많음) →
```

### 계층별 역할

```
[CPU 레지스터]
- 극도로 빠름 (0.3 나노초)
- 극도로 작음 (수백 바이트)
- CPU 내부 임시 저장
- 프로그래머 제어 불가능

[캐시 메모리]
- 매우 빠름 (1 나노초)
- 작음 (수MB)
- 자주 쓰는 데이터 저장
- CPU와 RAM 사이 완충

[RAM]
- 빠름 (100 나노초)
- 중간 (GB)
- 현재 실행 프로그램 저장
- 전원 필요

[SSD]
- 중간 (마이크로초)
- 큼 (TB)
- 프로그램/파일 저장
- 전원 불필요 (영구)

[HDD]
- 느림 (밀리초)
- 매우 큼 (PB)
- 백업/대용량 저장
- 전원 불필요 (영구)
```

## 💡 실제 동작 예시

### 인터넷 브라우징 시 메모리 사용

```
1. 컴퓨터 켜기
   - SSD에 저장된 OS 읽음
   - RAM에 로드

2. 브라우저 실행
   - SSD에서 프로그램 파일 읽음
   - RAM에 로드
   - L3 캐시에 자주 쓰는 부분 복사
   - L2, L1 캐시에도 복사

3. 웹사이트 접속
   - 데이터 RAM으로 수신
   - 이미지 파일 SSD에 임시 저장
   - 텍스트는 RAM 유지
   - CPU 캐시에 현재 보이는 부분 저장

4. 마우스 스크롤
   - 다음 부분 이미지 SSD에서 읽음
   - RAM으로 로드
   - CPU 캐시 업데이트
   - 즉시 화면 표시

5. 브라우저 종료
   - RAM의 데이터 삭제 (방문 기록 제외)
   - SSD의 캐시 파일만 남음
   - 대부분 메모리 해제
```

### 게임 플레이 시 메모리 사용

```
게임 로딩:
① SSD에서 게임 프로그램 읽음
② RAM에 로드 (수GB)
③ 그래픽 데이터 GPU 메모리에 로드
④ CPU 캐시에 게임 로직 저장

게임 중 지속적:
- 플레이어 위치: CPU 레지스터
- 근처 NPC: L3 캐시
- 현재 맵 세부: L2 캐시
- 현재 화면: L1 캐시 + GPU 메모리
- 전체 맵 데이터: RAM
- 게임 저장: SSD

게임 중 끊김:
- 필요 데이터를 SSD에서 읽음
- 로드 시간 발생 (수십초)
- SSD 빠를수록 로딩 빠름
- 이것이 SSD 중요 이유!
```

## 🔐 데이터 보안 vs 편의성

### 비휘발성 메모리의 보안 문제

```
문제:
- Flash Memory, SSD는 전원 꺼져도 데이터 유지
- 삭제해도 물리적으로 복구 가능
- 개인 정보, 금융 정보 위험

사례:
중고 노트북 구매
   ↓
이전 사용자 데이터 복구 도구로 읽음
   ↓
개인 정보, 암호, 파일 노출
```

### 데이터 보호 방법

```
1. 파일 삭제
   - 파일 시스템에서만 삭제
   - 물리적 데이터는 그대로
   - 복구 도구로 복구 가능

2. 포맷 (Format)
   - 드라이브 전체 초기화
   - 여전히 복구 가능
   - 전문 도구 필요

3. 암호화 (Encryption)
   - 읽을 수 없게 변환
   - 암호 없으면 무의미
   - 가장 안전 (준비 필수)

4. 보안 삭제 (Secure Erase)
   - 여러 번 덮어쓰기
   - SSD: TRIM + Overwrite
   - 시간 오래 걸림 (수시간)

5. 물리적 파괴
   - SSD 분해 및 소각
   - 가장 확실
   - 복구 불가능
```

## 📊 메모리 성능 지표

### 속도 측정 단위

```
나노초 (ns) = 10⁻⁹ 초 = 0.000000001초
    ↓
    1초 = 10억 나노초

예시:
- RAM 접근: 50~100 나노초
- SSD 읽기: 1~10 마이크로초 (1,000~10,000 나노초)
- HDD 읽기: 5~20 밀리초 (5,000,000~20,000,000 나노초)

비율:
RAM: 100 나노초
SSD: 10,000 나노초 (100배 느림)
HDD: 10,000,000 나노초 (100,000배 느림)
```

### 용량 측정 단위

```
1 Byte = 8 Bit
1 KB = 1,000 Byte = 1,000 × 8 = 8,000 Bit
1 MB = 1,000 KB = 800만 Bit
1 GB = 1,000 MB = 80억 Bit
1 TB = 1,000 GB = 8조 Bit

현대 기준:
- 스마트폰: 128GB~512GB
- 노트북: 256GB~1TB
- PC: 500GB~2TB
- 클라우드: 1TB~수십TB
```

## 🎯 요약: 메모리 선택 기준

### 각 메모리의 역할

```
용도별 최적 선택:

매우 빠른 임시 작업 (마이크로초):
→ SRAM (CPU 캐시)

빠른 작업 (나노초~마이크로초):
→ DRAM (RAM)
→ 용도: 게임, 동영상 편집, 여러 프로그램 동시 실행

저렴한 대용량 저장 (마이크로초):
→ NAND Flash (SSD)
→ 용도: 프로그램 설치, 파일 저장

장기 보관 (밀리초):
→ HDD (하드 드라이브)
→ 용도: 백업, 대용량 저장, 나중에 쓸 데이터

특수 용도:
→ NOR Flash (펌웨어)
→ ReRAM (미래 기술)
→ MRAM (우주/군사)
```

### 업그레이드 우선순위

```
1순위: SSD 추가/교체
   - 가장 큰 성능 향상
   - HDD → SSD: 10배 빨라짐
   - 비용 대비 효과 최고

2순위: RAM 증설
   - 다중 프로그램 실행 개선
   - 4GB → 8GB: 체감 향상
   - 16GB 이상이면 일반 사용자 충분

3순위: CPU 업그레이드
   - 전문가 작업 필요
   - 일반 사용자는 불필요
```

## 💾 미래의 메모리 기술

### 2030년대 예측

```
기술            | 상태         | 가능성
-------------|------------|--------
ReRAM       | 개발 중      | 높음 (Flash 대체)
FeRAM       | 초기 상용화  | 중간 (특정 분야)
MRAM        | 초기 상용화  | 낮음 (비용)
PIM (메모리 내 처리) | 연구 | 높음 (혁신)
홀로그래픽  | 연구        | 낮음 (장기)
```

### PIM (Processing In Memory)

```
혁신 개념:
메모리 + CPU 통합
   ↓
데이터 움직임 최소화
   ↓
극도의 속도 향상

예시:
현재: 메모리 → CPU → 계산 → 메모리
      (데이터 왕복 이동)

미래: 메모리 내에서 계산 수행
      (데이터 이동 없음)

장점:
- 나노초 → 수십 배 빠름
- 전력 극도 절감
- AI 처리 혁신적 개선
```

## 🏭 반도체 메모리와 배관 시공의 연관성

### 메모리 공장의 복잡한 배관 시스템

```
반도체 메모리 생산 과정에서 필요한 배관:

1. 초순수 물 (DI수) 배관
   - 목적: 칩 세정, 냉각
   - 순도: 1ppt (극도로 순수)
   - 배관: SUS 316L, φ10~50mm
   - 압력: 1~5 bar
   
2. 극저온 냉각 배관
   - 목적: 극저온 공정 (NAND 제조)
   - 온도: -50°C ~ -100°C
   - 배관: 특수 동합금 + 단열
   - 복잡도: 매우 높음

3. 특수 가스 배관
   - 목적: 증착, 식각 가스
   - 가스: Ar, CF₄, SiH₄ 등
   - 순도: 99.999% 이상
   - 배관: SUS 304, 매우 정밀

4. 폐액 처리 배관
   - 목적: 유해 화학약품 배출
   - 재질: PTFE (테플론)
   - 단열: 절대 필요
   - 누수 감시: 24시간

5. 정밀 에어 압축 배관
   - 목적: 자동화 장비 구동
   - 청정도: Class 2 (극도 청정)
   - 배관: 동, 스테인리스
   - 필터: 다단계 (99.99% 제거)
```

### 메모리 공장 배관의 특수성

```
일반 공장 배관:
- 수도, 하수, 에어만 관리
- 정밀도 ±5mm 수준

메모리 공장 배관:
- 초순수, 극저온, 특수 가스, 폐액
- 정밀도 ±0.5mm 수준 (10배 엄격)
- 누수 1mL도 불량 원인
- 온도 편차 ±1°C 이내 유지 필수
- 24시간 모니터링 필수

설계 난도:
- 일반 배관 대비 10배 이상 복잡
- 국제 표준 준수 필수
- 컴퓨터 모의 설계 필수

비용:
- 메모리 공장 배관: 전체 비용 30~40%
- 일반 공장 배관: 전체 비용 5~10%

미래 기회:
- 반도체 메모리 기술 발전
- 극저온 기술 강화
- 초순수 시스템 고도화
- 한국 배관설계 회사의 기회 확대
```

## 💡 핵심 정리

### "데이터는 전자의 움직임이다"

```
메모리의 본질:
- 전자를 넣는다 = "1" 저장
- 전자를 뺀다 = "0" 저장
- 전자를 세어본다 = 데이터 읽기
- 전자를 가두었다 유지한다 = 영구 저장
```

### "속도 vs 용량 트레이드오프"

```
매우 빠름 + 매우 적음 = 레지스터/캐시
빠름 + 중간 = RAM
느림 + 많음 = SSD/HDD

현대 기술의 과제:
- 더 빠르면서
- 더 많은 용량
- 더 저렴하게
```

### "미래는 다층화"

```
미래 컴퓨터:
- 극고속 캐시 (ReRAM)
- 고속 작업 메모리 (DRAM 개선)
- 대용량 저장 (NAND Flash 또는 3D XPoint)
- 장기 보관 (HDD 또는 테이프)

세 가지 원칙이 계속 적용:
1. 빠를수록 비쌈
2. 많을수록 느림
3. 영구 저장은 느림
```
