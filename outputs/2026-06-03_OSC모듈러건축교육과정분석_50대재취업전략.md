## 2. OSC모듈러 건축 산업 시장성

### 2.1 산업 성장 동향

```
📈 시장 전망 (2026년 기준):

현황:
• 전 세계 모듈러 건설 시장: 연 10% 이상 성장
• 한국 모듈러 시장: 초기 단계 → 급성장 중
• 정부 지원: "스마트 건설" 정책 추진 중

성장 동력:
1. 건설 인력 부족
   └─ 고령화로 젊은 기술자 부족
   └─ 모듈러 = 자동화로 대응
   
2. 공사기간 단축 수요
   └─ 개발사들의 "빨리 짓고 팔아야 함"
   └─ 40~50% 공기 단축 (큰 매력)
   
3. 품질 표준화
   └─ 공장 제작 = 일관된 품질
   └─ 현장 최소화 = 하자 감소
   
4. 글로벌 트렌드
   └─ 미국, 일본, 북유럽: 이미 대중화
   └─ 한국: "10년 늦음" = "기회"
```

## 3. 50대에게 최적의 이유

### 3.1 왜 이 교육이 50대에게 완벽한가?

#### 이유 1️⃣: 체계적인 교육 기간 (6개월)

```
기존 고민:
"짧은 교육은 현장에서 쓸 수 있을까?"
"충분히 배울 시간이 있을까?"

이 교육의 장점:
✅ 6개월 심층 교육으로 실력 확실히 갖춤
✅ 이론 + 실습 + 자격증 완성까지 충분한 시간
✅ 충분한 훈련으로 취업 경쟁력 극대화

효과:
• 현장 투입 즉시 능력 발휘
• 3개 자격증 취득 여유 확보
• 심리적 자신감 충분히 형성
```

#### 이유 2️⃣: 실무형 교육 (이론 최소)

```
50대가 싫어하는 교육:
❌ "너무 이론적"
❌ "현장과 동떨어짐"
❌ "실용성 없음"

이 교육의 강점:
✅ 80% 실습 중심
✅ 현장 수준의 환경
✅ 졸업 후 바로 일 가능

사례:
"교육 끝나고 다음 주부터 일했어요"
```

#### 이유 3️⃣: 높은 임금 (200만원대 아님)

```
50대 재취업 현실:
일반 직종 → 월 200~250만원 (초라함)

모듈러 건설 기술자:
용접 기술자 → 월 300~400만원
BIM 설계자 → 월 350~450만원
현장관리자 → 월 450~600만원

효과:
"임금 하락을 50% 이상 완화"
```

#### 이유 4️⃣: 나이 차별 없음

```
일반 직무 재취업:
"50대는 안 봅니다" (차별)

건설 기술 분야:
"나이 상관없어, 기술이 있으면 됨"

이유:
• 인력 부족 심각
• 경험 있는 사람 환영
• 젊은이들이 안 하는 일
```

#### 이유 5️⃣: 신체 적응 가능

```
50대 건강 우려:
"용접 같은 거 체력 되나?"

현실:
✅ 용접은 "손과 눈"이 중요
✅ 나이 크게 안 타함
✅ 일반 공사장보다 편함
  • 공장 실습: 실내 (날씨 안 타)
  • 과하지 않은 작업량
  • 안전 환경 좋음

의료 통계:
"용접 기술자 평균 근무 연수: 25년 이상"
```

#### 이유 6️⃣: 자격증의 높은 가치

```
취득 자격증 3개:

1. 이산화탄소아크용접기능사
   • 국가기술자격 (평생 유효)
   • 해외 취업도 가능
   • 건설업 필수 인력

2. CAD 실무능력평가
   • 설계 분야 기본 자격
   • 다양한 산업 활용

3. SketchUp 국제인증
   • 글로벌 인증
   • 해외 기업 진출 가능

효과:
"3개의 공식 자격증으로 경력 증명"
```

## 4. 구체적 실행 전략

### 4.1 사전 준비 (교육 신청 전)

#### Step 1: 건강 점검

```
필수 검진 (교육 시작 전 1개월):

□ 종합 건강검진
  • 심장 건강 (용접 열과 스트레스)
  • 폐 건강 (용접 연기)
  • 눈 건강 (용접은 눈 피로)
  • 근골격 건강 (손목 부상 확인)

□ 청력검진
  • 용접 소음 대비
  • 청력 보호 필요한지 판단

□ 정신건강 점검
  • 새로운 배움에 대한 불안감
  • 스트레스 관리 방법
  
소요비용: 30~50만원
효과: 교육 안전하게 완료 가능
```

#### Step 2: 심리 준비

```
마음가짐:

✅ "이건 나를 위한 투자"
✅ "6개월이면 충분히 배울 수 있다"
✅ "젊은이처럼 할 필요 없다"
✅ "기술과 경험이 무기다"
```

### 6.2 50대의 강점을 극대화하는 방법

```
50대 = "약점"이 아닌 "자산"

약점으로 취급받지 않는 이유:
1. 기술 기반 산업
   → 나이보다 "기술"
   → 나이 차별 거의 없음

2. 인력 부족 심각
   → 경력자 환영
   → "50대 환영합니다"

3. 안정적 인력 필요
   → 젊은 기술자의 이직률 높음
   → 50대의 장기 근속 환영

4. 경험의 가치
   → 건설 경험 있으면 시작 1주 단축
   → "이미 기초 있네요" 평가
```
