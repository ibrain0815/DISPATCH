## 1. OSC 모듈러 건설이란?

### 1.1 개념 정의

**OSC (Off-Site Construction)**: 건설 부품과 모듈을 공장에서 미리 제조한 후, 현장에서 조립하는 건설 방식입니다. 전통적인 현장 중심 건설과 달리 통제된 환경에서 정밀하게 생산됩니다.

**주요 특징:**
- 🏭 공장에서 80~90% 제조 후 현장 조립
- ⚡ 공기 단축 (30~40%)
- 💰 원가 절감 가능성
- 🌱 친환경적 생산
- ✅ 품질 관리 우수

### 1.2 모듈러 건설의 종류

```
1. 경량철골 모듈러 (Light Steel Modular)
   - 철골 프레임에 내외부 마감재 설치
   - 3~10층 건물에 주로 사용
   - 영국, 호주에서 많이 사용

2. 콘크리트 모듈러 (Concrete Modular/PPVC)
   - 프리캐스트 콘크리트 활용
   - 고층 건물 가능
   - 싱가포르, 일본에서 많이 사용

3. 하이브리드 방식
   - 경량철골 + 콘크리트 조합
   - 각 장점 활용
```

## 2. 해외 성공 사례

### 2.1 영국 - 선진 OSC 기업 주도

#### **Laing O'Rourke (라이닝 오루크)**

세계 최고 수준의 모듈러 기술을 보유한 영국의 건설회사입니다.

**2025년 목표:**
- 건설작업의 **90%를 공장생산**으로 전환
- 프로젝트 구성요소의 70%를 오프사이트에서 제조
- 생산성 **60% 향상**
- 공기 **30% 단축**

**주요 프로젝트:**
```
✓ 런던 교통국 건물 리모델링
✓ 학교, 병원 등 공공시설
✓ 주거 건물 다수
```

#### **GS건설 - Elements Europe (엘리먼츠 유럽)**

한국 GS건설의 영국 자회사로, 모듈러 기술을 글로벌 시장에 확대하고 있습니다.

**캠프힐 사업 (버밍엄)**
```
프로젝트 규모:
- 지상 3~26층, 6개 동
- 총 550가구 규모의 임대주택
- 상업시설 포함

공법: 철골 모듈러공법
특징: 대규모 모듈러 프로젝트로 글로벌 인정
```

#### **영국 시장의 특징**
- 1940년대부터 모듈러공법 도입 (전후 복구사업)
- 정부의 지속적인 정책 지원
- 혁신 기술 기업의 활발한 활동
- 건설 인력 부족 해결 수단으로 주목

### 2.2 싱가포르 - PPVC 중심의 선도

#### **정부 주도 전략**

싱가포르 건설부(BCA)는 **공공 강제정책**으로 모듈러를 적극 추진합니다.

**주요 목표 및 성과:**
```
현황: 공공주택의 약 65% 모듈러로 진행
목표: 공공 프로젝트 대다수를 모듈러로 전환

추진 배경:
- 인구 밀집, 주택 공급 급박
- 건설 인력 부족 심각
- 건설 기간 단축 필요
- 친환경 정책 강화
```

#### **PPVC (Prefabricated Prefinished Volumetric Construction)**

콘크리트 기반의 모듈러 건설 방식입니다.

**특징:**
- 프리캐스트 콘크리트 유닛
- 실내 마감재까지 공장에서 완성
- 현장에서는 조립만 하면 됨
- 품질 일관성 우수
- 높은 층수 건물 가능

**장점:**
```
✓ 공기 25~30% 단축
✓ 품질 편차 거의 없음
✓ 공장에서 생산 비용 절감
✓ 환경 영향 최소화
✓ 노동력 절감
```

#### **싱가포르의 성공 요인**
- 정부의 강한 정책 의지
- 제조 시설의 집중화
- 표준화된 설계 시스템
- 국가 차원의 기술 개발 투자

### 2.3 일본 - 전통과 혁신의 결합

#### **스웨덴, 유럽 기술 도입**

일본은 스웨덴 및 유럽 국가의 모듈러 기술을 도입하여 자국화했습니다.

**특징:**
- PC (Precast Concrete) 기반 OSC 광범위 사용
- 경량철골 모듈러도 적극 채택
- 공공 프로젝트에 전략적 도입
- 숙련된 제조업체 네트워크 구축

**주요 프로젝트:**
```
✓ 공공주택 대량 공급
✓ 학교, 병원 리모델링
✓ 상업 시설 건설
```

#### **일본 시장의 특징**
- 오랜 PC 기술 경험
- 정밀한 제조 문화
- 정부 정책 지원
- 건설 인력 고령화 대응

```
스마트 홈 기술 탑재:
✓ 에너지 관리 시스템
```

## 4. 글로벌 시장 규모 및 전망

### 4.1 시장 성장 추이

#### **현재 시장 규모 (2025년)**

```
글로벌 모듈러 건설시장: 약 1,088억 달러
성장률: 연평균 8.7% (2025~2030)
```

#### **향후 시장 규모 전망**

```
2025년: 약 108.8조원 (1,088억 달러)
↓
2030년: 약 162.5조원 추가 성장
증가규모: 5,425억 달러 (약 54.25조원)
↓
2032년: 약 189.1조원 규모 (1,891억 달러)
전체 성장률: 2025~2032년 CAGR 6.9%
```

### 4.2 지역별 성장

```
북미: 모듈러 주택 수요 증가 (인력 부족 해결)
유럽: 영국, 스칸디나비아 주도적 성장
아시아태평양: 싱가포르, 일본, 호주 급성장
한국: 2025~2030 급속 확대 예상
```

### 4.3 2025~2026년 주요 변화

#### **수요 트렌드**

```
1. 우측형 모듈러 구조 증가
   → 효율성 높은 공간 활용
   → 이동성 있는 건설

2. 생산 효율 증가
   → 공장 시설 현대화
   → 자동화 수준 향상

3. 비용 경쟁력 강화
   → 규모의 경제 달성
   → 기존 공법과 가격 접근
```

#### **산업 특성 변화**

```
미래 건설 프로젝트의 4대 특징:
1. Faster (빠름) - 모듈러/프리팹
2. Precise (정확) - BIM/AI 기반
3. Greener (친환경) - ESG 중심
4. Industrialized (산업화) - 공장 품질 관리
```

## 6. 주요 과제 및 해결 방안

### 6.1 현재 직면한 주요 과제

#### **1) 고층 모듈러 기술 미흡**

```
과제: 5층 이상 고층 기술 부족
이유: 구조 안정성, 시공 연결부 복잡성
현황: 기술 검증 단계

해결 방안:
✓ 정부-기업 공동 R&D 투자 확대
✓ 대학 연구소 기술 개발 지원
✓ 국제 기술 교류 강화
✓ 시공 시범 프로젝트 확대
```

#### **2) 전문 인력 부족**

```
과제: 설계·제조·시공 전문가 부재
이유: 새로운 공법, 기술 난이도 높음
현황: 산업 초기 단계

해결 방안:
✓ 직업 교육 프로그램 신설
✓ 대학 커리큘럼 개발
✓ 국내외 교육 기회 확대
✓ 인센티브 제공 (급여, 복지)
```

#### **3) 경제성 문제**

```
과제: 기존 공법 대비 약 30% 공사비 높음
이유: 
- 제조 시설 소규모
- 물량 제한으로 규모의 경제 미흡
- 설계·기술 비용 높음

해결 방안:
✓ 대량 발주를 통한 규모의 경제
✓ 자동화 설비 투자
✓ 표준화 설계 확대
✓ 부품 공급 체인 구축
```

#### **4) 설계·제조 표준화 부족**

```
과제: 프로젝트별 맞춤형 설계로 효율성 저하
이유: 기준 미흡, 경험 부족

해결 방안:
✓ 모듈 표준화 기준 확립
✓ BIM 기반 설계 표준 수립
✓ 제조 프로세스 표준화
✓ 국제 표준 벤치마킹
```
