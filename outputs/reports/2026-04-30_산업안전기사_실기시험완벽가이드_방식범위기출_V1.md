# 산업안전기사 실기시험 완벽 가이드
## 시험 방식, 범위, 예상 기출문제

---

## 1. 실기시험 개요

### 1.1 시험 구성
- **시험 과목**: 산업안전관리실무 (1개 과목)
- **시험 형식**: 필답형 + 작업형 복합형
- **총 시험 시간**: 약 3시간
- **배점 구성**:
  - 필답형: 55점 (약 1시간 30분)
  - 작업형: 45점 (약 1시간 30분)

### 1.2 합격 기준
- **최종 합격 기준**: 필답형 + 작업형 합산 **60점 이상**
- **특징**: 
  - 필답형이 0점이어도 작업형 고득점으로 보충 가능
  - 작업형이 0점이어도 필답형 고득점으로 보충 가능
  - 단, 실제로는 두 영역 모두 적절한 점수 필요

### 1.3 최근 출제 경향 분석

**2023년 이후 변화**
- 신출 문제(기출이 아닌 새로운 문제) 비중 증가
- 기존 기출 내용의 변형된 문제 출제
- 난이도 점진적 상향
- 실무 적용 능력 강조

## 2. 필답형 시험 상세 분석

### 2.1 필답형 시험 개요

#### 시험 형식
- **방식**: 종이 시험지 (수기 작성)
- **시간**: 약 1시간 30분
- **문항수**: 약 13~15문항
- **문제유형**: 주관식 (단답형, 서술형, 계산형)
- **배점**: 총 55점

#### 문제 유형별 분석

**1️⃣ 법령 조문형 (약 40%)**
- 산업안전보건법 조문 그대로 외워 쓰기
- 규칙 조문 정확히 암기
- 중대재해처벌법 내용

예) "산업안전보건법 제33조 안전관리자의 직무를 설명하시오"

**2️⃣ 단답형 (약 30%)**
- 용어 정의
- 개념 설명
- 기준값 입력

예) "안전보건위원회 개최 주기는?"
정답: "분기마다(3개월마다) 개최"

**3️⃣ 서술형 (약 20%)**
- 절차 설명
- 방법 설명
- 사례 분석

예) "위험성평가 5단계 프로세스를 설명하시오"

**4️⃣ 계산형 (약 10%)**
- 수치 계산
- 기준 판단

예) "50인 이상 300인 미만 사업장의 안전관리자 필요 인원은?"
정답: "1명 이상"

### 2.2 필답형 출제 범위 상세

#### 주제 1: 산업안전보건법 및 규칙 (약 35%)

**자주 출제되는 조문**
- 제33조: 안전관리자의 직무 (매우 자주 출제)
- 제34조: 보건관리자의 직무
- 제2조: 정의 (중대재해, 사업장 등)
- 제4조: 기본 의무
- 제5조: 사업주의 의무
- 제제3장: 근로자의 의무
- 제19조: 안전관리자 선임 기준
- 제20조: 보건관리자 선임 기준
- 제54조: 안전교육의 기준
- 제110조: 중대재해 발생 보고

**법령 외우기 팁**
- 조문 번호까지 정확히 암기
- 법, 규칙, 고시 구분하기
- 개정된 최신 내용 반영

#### 주제 2: 중대재해처벌법 (약 15%)

**출제 포인트**
- 적용 대상 (사업주, 경영진)
- 처벌 규정 (벌금 종류와 액수)
- 중대재해 정의 (사망, 부상, 질병)
- 예방 조치 (사실상의 경영 책임자)

#### 주제 3: 위험성평가 및 관리 (약 20%)

**2024년 신규 강화 항목**
- 위험성평가 5단계 프로세스
  1단계: 위험 요소 파악
  2단계: 위험도 결정
  3단계: 위험도 평가
  4단계: 개선조치 결정
  5단계: 조치 이행

- 위험도 계산식
  위험도 = 발생가능성 × 심각도
  
- 개선 조치 우선순위

#### 주제 4: 안전보건교육 (약 12%)

**자주 출제되는 내용**
- 정기교육 (연간 8시간, 분기별 2시간씩)
- 특별교육 (특정 작업 종사자)
- 신규 근로자 교육 (8시간)
- 관리감독자 교육 (16시간)

#### 주제 5: 보호장구 및 안전 표지 (약 10%)

**출제 내용**
- 안전모 규격
- 안전화 규격
- 안전벨트/안전대 규격
- 호흡용 보호구 종류
- 청력보호구 종류

#### 주제 6: 기타 실무 내용 (약 8%)

- 산업 재해 통계
- 안전점검 기준
- 특수건강진단 기준
- 보고 및 기록

### 2.3 필답형 기출 문제 경향

#### 2023년 이후 주요 변화

**신출 문제 증가**
- 기존 기출과 정확히 일치하지 않는 문제
- 조문은 기출과 같으나 다른 각도에서 질문
- 응용 능력 테스트

**난이도 상향**
- 법령 조문만으로 답변 불가능
- 실제 상황 적용 능력 요구
- 복합 상황 판단 필요

#### 기출 문제 반복 패턴

**높은 반복률 항목**
1. 안전관리자 직무 (80% 이상 반복)
2. 안전교육 시간 (70% 이상 반복)
3. 중대재해 정의 (65% 이상 반복)
4. 위험성평가 절차 (60% 이상 반복)

## 4. 작업형 시험 상세 분석

### 4.1 작업형 시험 개요

#### 시험 형식
- **방식**: 컴퓨터 기반 (PC 화면에서 답안 작성)
- **시간**: 약 1시간 30분
- **문항수**: 보통 3~5개 동영상 시나리오
- **문제유형**: 동영상 시청 후 위험요소·안전대책 기술
- **배점**: 총 45점

#### 시험 진행 방식

**순서**
1. 동영상 재생 (약 1~3분)
2. 각 동영상 후 문제 제시 (약 10개 빈칸 채우기)
3. 컴퓨터 키보드로 답안 작성
4. 다음 동영상으로 진행
5. 총 3~5개 동영상 분석

**점수 배점**
- 각 동영상당 약 9~15점
- 위험요소 기술: 점수 배분
- 안전대책 기술: 점수 배분

### 4.2 작업형 출제 범위 - 산업별 분석

#### 주제 1: 용접·절단 작업 (약 20%)

**자주 출제되는 위험 요소**
- 감전 위험
- 화상 위험
- 화재·폭발
- 눈 손상 (자외선)
- 흡입 위험 (흄)

**자주 출제되는 안전대책**
- 자동전격방지기 설치 (차단식, 감지식, 감시식)
- 용접 차폐막 설치
- 환기 장치
- 감시자 배치
- 소화기 비치

**예상 기출 패턴**
```
[동영상] 용접 작업 중 감전 위험 상황
- 손상된 전선 노출
- 젖은 환경에서의 작업
- 접지 미설치

[문제] 
1. 위 영상에서 발견된 위험요소 3가지
   → 감전 위험, 화상 위험, 화재 위험

2. 각 위험요소별 안전대책 3가지
   → 자동전격방지기 설치
   → 습기 제거 및 절연 관리
   → 주변 가연물 제거, 소화기 배치
```

#### 주제 2: 화학물질 취급 (약 25%)

**자주 출제되는 작업**
- 석면 취급
- 유해 액체 취급
- 페인트/용제 사용
- 먼지 발생 작업

**자주 출제되는 위험 요소**
- 흡입 위험
- 피부 접촉 위험
- 화염 위험
- 폭발 위험

**자주 출제되는 안전대책**
- 개인보호장구 (마스크, 장갑, 보호복)
- 환기 시설
- 국소배기시스템
- 안전교육
- 응급세척 시설

**예상 기출 패턴**
```
[동영상] 석면 취급 작업 - 비산 방지 미흡
- 보호복 미착용
- 마스크 부적절 (일반 마스크)
- 습식 작업 미시행

[문제]
1. 석면 취급 시 발생 가능한 위험요소
   → 석면 비산, 흡입 위험, 직업성 질병

2. 안전작업 수칙 5가지
   → 습식 작업 시행
   → 전용 호흡용 보호구 착용
   → 보호복 완전 착용
   → 작업 후 오염 제거
   → 폐기물 안전 처리
```

#### 주제 3: 사무실 작업 (VDT) (약 15%)

**자주 출제되는 위험 요소**
- 잘못된 자세
- 목·어깨 부담
- 눈 피로
- 손목터널증후군

**자주 출제되는 안전대책**
- 의자 높이 조정
- 모니터 높이 조정
- 휴식 시간 확보
- 스트레칭 운동
- 조명 개선

**예상 기출 패턴**
```
[동영상] VDT 작업 중 인간공학 미흡
- 모니터가 눈 위에 위치
- 의자 높이 부적절
- 계속 앉아만 있기

[문제]
1. 위 영상에서 발견된 안전 미흡 사항 3가지
   → 모니터 높이 부적절
   → 의자 높이 불량
   → 휴식 미흡

2. 개선 방안 3가지
   → 모니터 중심을 눈 수평선 아래로 조정
   → 의자 높이를 발이 바닥에 닿게 조정
```

## 6. 작업형 시험 준비 전략

### 6.1 동영상 학습 전략

#### 기출 동영상 분석 방법
1. **1차 시청**: 전체 상황 파악
2. **2차 시청**: 위험요소 찾기
3. **3차 시청**: 안전대책 찾기
4. **4차 이상**: 답안 작성 연습

#### 학습 자료
- 모두CBT: 2016~2025년 작업형 모음
- 나눔CBT: 실전 모의고사
- 에듀윌 교재: 동영상 복원 및 상세 설명

### 6.2 작업형 답안 작성 기법

#### 좋은 답안의 특징
1. **명확성**: 위험요소와 대책이 명확히 구분됨
2. **구체성**: 일반적 표현 아닌 구체적 내용
3. **정확성**: 안전 용어 정확히 사용
4. **완전성**: 모든 위험 상황 포함

#### 나쁜 답안의 특징
1. 모호한 표현 ("위험이 있다" vs "감전 위험")
2. 불완전한 내용 (위험요소만 또는 대책만)
3. 부정확한 용어 ("안전 벨트" vs "안전대")
4. 실행 불가능한 대책

### 6.3 출제 경향 예측

**2024년 이후 강화 영역**
- 화학물질 취급 (석면, 유해액체)
- 개인보호장구 정확성
- 인간공학 (VDT 작업)
- 정법령 기반 대책
