# 반도체 공장의 화학물질: 무기화학물질과 유기화학물질 분류

**작성일**: 2026년 6월 1일  
**대상**: 비전공자도 이해할 수 있는 반도체 공장 화학물질 가이드

---

## 🎯 1. 개요

### 1.1 반도체 공장의 화학물질이란?

```
반도체 공장에서 사용되는 화학물질:

"반도체(칩)를 만드는 과정에서 필요한 모든 화학 물질"

비유:
┌─────────────────────────────────┐
│ 요리에 비유하면               │
├─────────────────────────────────┤
│ 밀가루, 계란 = 원재료           │
│ 소금, 설탕 = 조미료             │
│ 기름 = 용제 (흐르게 하는 것)    │
│ 불 = 화학 반응                 │
│ = 반도체 만드는 과정           │
└─────────────────────────────────┘

반도체 공장의 화학물질도 마찬가지:
- 원료 화학물질
- 공정용 화학물질
- 세정용 화학물질
→ 모두 필수!
```

### 1.2 무기화학물질 vs 유기화학물질 비교

| 구분 | 무기화학물질 | 유기화학물질 |
|------|-----------|----------|
| 탄소 포함 | ❌ 없음 | ✅ 있음 |
| 주요 역할 | 식각, 세정, 산화 | 패턴 형성, 세정, 보호 |
| 상태 | 액체, 고체, 기체 | 대부분 액체 |
| 안정성 | 높음 | 낮음 (휘발성) |
| 온도 견디기 | 매우 강함 | 약함 |
| 환경영향 | 중간 | 높음 |
| 비용 | 저렴 | 매우 비쌈 |

### 1.3 반도체 공장에서의 중요성

```
화학물질 없으면?
→ "칩 제조 불가능" (100% 필수)

올바르게 사용하면?
✓ 고품질 반도체 생산
✓ 수율 증가 (더 많이 만듦)
✓ 원가 절감

잘못 사용하면?
✗ 불량품 폭증
✗ 안전 사고 발생
✗ 환경 오염
✗ 생산 중단
```

## 🧪 2. 무기화학물질 (Inorganic Chemicals)

### 2.1 정의 및 특징

무기화학물질은 탄소(C)를 포함하지 않는 화학물질입니다. 반도체 공장에서 다음과 같은 역할을 합니다:

1. **식각 (Etching)** - 불필요한 부분을 깎아냄
2. **세정 (Cleaning)** - 불순물과 오염물 제거
3. **산화 (Oxidation)** - 절연층 및 산화층 형성
4. **도핑 (Doping)** - 불순물을 의도적으로 추가해서 전기 특성 조절

### 2.2 주요 무기화학물질 12가지

#### 1️⃣ 황산 (Sulfuric Acid, H₂SO₄)

```
상태: 액체 (투명, 무색)
농도: 98% 순도 사용

쓰임새:
├─ 세정제 (주 용도)
│  └─ 강력한 산화제로 불순물 완전 제거
├─ 전처리 (Pre-treatment)
│  └─ 웨이퍼 표면 준비
└─ 폐수 처리

특성:
✓ 매우 강한 산 (pH < 0)
✓ 발열반응 (많은 열 발생)
✓ 강력한 탈수제

⚠️ 위험성:
- 극심한 화상 위험
- 물에 황산을 넣지 말 것!
  (반대: 황산에 물을 천천히 넣기)

보관:
- 강화 플라스틱 용기
- 통풍 시설이 있는 장소
```

#### 2️⃣ 불산 (Hydrofluoric Acid, HF)

```
상태: 액체 (투명, 무색)
농도: 49% 수용액 일반적

쓰임새:
├─ 산화층 제거 (가장 중요!)
│  └─ 실리콘 다이옥사이드(SiO₂) 제거
├─ 유리 제거 공정
└─ 산화물 식각

특성:
✓ 유일하게 유리를 녹일 수 있는 산
✓ 반도체 공정의 핵심 물질
✓ 약한 산처럼 보이지만 극히 위험

⚠️ 위험성:
- 가장 위험한 화학물질 TOP 3!
- 극소량도 치명적일 수 있음
- 피부 투과 후 내부 조직 손상
- 골 손상 및 저칼슘혈증 유발
- 호흡기 손상 가능

보관:
- 특수 고분자 용기만 사용 (금속 절대 불가)
- 이중 안전 장치
- 응급 치료약 (칼슘 글루콘산염) 비치 필수
```

#### 3️⃣ 인산 (Phosphoric Acid, H₃PO₄)

```
상태: 액체 (투명, 무색)
농도: 85% 수용액

쓰임새:
├─ 알루미늄 식각
│  └─ 알루미늄 배선 패턴 형성
├─ 실리콘 니트라이드 식각
└─ 세정 및 전처리

특성:
✓ 온화한 산 (약한 산)
✓ 선택적 식각 가능 (원하는 부분만)
✓ 비교적 안전한 편

⚠️ 위험성:
- 중간 정도의 위험
- 피부 및 눈 자극

보관:
- 일반 플라스틱 용기 가능
- 상온 보관 가능
```

#### 4️⃣ 염산 (Hydrochloric Acid, HCl)

```
상태: 액체 (투명, 무색)
농도: 37% 수용액

쓰임새:
├─ 금속 산화물 제거
├─ 금속 오염물 제거
└─ 세정 및 에칭

특성:
✓ 빠른 식각 속도
✓ 저비용
✓ 휘발성 (HCl 가스 발생)

⚠️ 위험성:
- 강한 산
- 유독 가스(HCl) 발생 위험
- 호흡기 손상

보관:
- 플라스틱 용기
- 반드시 통풍 필수
```

#### 5️⃣ 수산화칼륨 (Potassium Hydroxide, KOH)

```
상태: 고체(펠릿) 또는 액체
색상: 흰색 펠릿 또는 무색 용액

쓰임새:
├─ 실리콘 에칭 (이방성 에칭)
│  └─ 결정 방향 선택적 식각
├─ 에칭액 성분
└─ 세정액

특성:
✓ 강한 염기 (pH > 14)
✓ 비용이 저렴
✓ 보통 27.5% 수용액으로 사용

⚠️ 위험성:
- 화상 위험 (화학 화상)
- 피부 침식
- 눈 손상

보관:
- 밀폐 용기 (습기 차단)
- 습도 조절 필수
```

#### 6️⃣ 염화철(III) (Ferric Chloride, FeCl₃)

```
상태: 고체 또는 액체
색상: 갈색 (수용액)

쓰임새:
├─ 구리 에칭 (가장 중요)
│  └─ 구리 배선 패턴 형성
├─ 기타 금속 에칭
└─ PCB 제조에도 사용

특성:
✓ 선택적 에칭
✓ 반복 사용 가능 (비용 절감)

⚠️ 위험성:
- 중간 정도 위험
- 피부 및 눈 자극

보관:
- 플라스틱 용기
- 산성 환경 유지
```

#### 7️⃣ 질산은 (Silver Nitrate, AgNO₃)

```
상태: 고체(결정) 또는 액체
색상: 무색 결정 또는 무색 용액

쓰임새:
├─ p형 도핑
│  └─ 반도체에 은 이온 추가
├─ 도전성 페이스트
└─ 특수 용도

특성:
✓ 빛에 민감 (광반응성)
✓ 비용이 매우 비쌈
✓ 소량으로도 효과 큼

⚠️ 위험성:
- 독성 물질
- 피부 변색 (회색→검은색)
- 눈 손상

보관:
- 갈색 병 (빛 차단 필수)
- 냉암소 보관 (냉장고 권장)
```

#### 8️⃣ 이산화규소 (Silicon Dioxide, SiO₂)

```
상태: 고체 (분말)
색상: 무색 또는 흰색

쓰임새:
├─ 절연층 (핵심!)
│  └─ 전자 흐름 차단
├─ 산화층 형성
└─ 구조적 강도 제공

특성:
✓ 반도체 기본 재료
✓ 온도에 매우 강함
✓ 화학적 안정성 높음

⚠️ 위험성:
- 규소 분진 흡입 위험
- 규폐증 (장기 노출 시)

보관:
- 분진 방지 용기
- 건조한 환경 유지
```

#### 9️⃣ 산화알루미늄 (Aluminum Oxide, Al₂O₃)

```
상태: 고체 (분말)

쓰임새:

✓ 높은 경도 (매우 단단함)
✓ 극도로 높은 온도 견딤
✓ 화학 안정성 최고 수준

⚠️ 위험성:
- 분진 흡입 위험 (비교적 낮음)
- 가장 안전한 무기 물질 중 하나

보관:
- 일반적인 저장소 가능
```

#### 🔟 암모니아 (Ammonia, NH₃)

```
상태: 기체 (냉동 압축 저장)
냄새: 매우 자극적 & 강함

보관:

#### 1️⃣1️⃣ 산소 (Oxygen, O₂)

## 🧬 3. 유기화학물질 (Organic Chemicals)

### 3.1 정의 및 특징

유기화학물질은 탄소(C)를 포함하는 화학물질입니다. 다음 역할을 합니다:

1. **포토리소그래피** - 패턴 형성의 핵심!
2. **세정** - 유기 불순물 제거
3. **코팅** - 보호층 형성
4. **접착** - 층 결합 및 결착

**주요 특징**:
- 대부분 휘발성 (증발 잘 됨)
- 매우 높은 순도 필요 (99.99%)
- 온도에 민감할 수 있음
- 환경 영향 큼

### 3.2 주요 유기화학물질 13가지

#### 1️⃣ 포토레지스트 (Photoresist)

```
상태: 액체 (점성 있음)
색상: 황색~적색

쓰임새:
├─ 패턴 형성 (가장 핵심!)
│  └─ 빛에 반응해서 패턴 만듦
├─ 마스크 역할 (다른 부분 보호)
└─ 식각 보호층

특성:
✓ 자외선(UV)에 민감
✓ 나노 단위 정확도
✓ 매우 비쌈 (mm당 수백만원)
✓ 계속 발전 중 (EUV용 개발)

작동 원리:
1. 웨이퍼에 포토레지스트 코팅
2. 자외선(UV) 또는 X선 조사
3. 빛받은 부분만 화학 반응
4. 현상액으로 반응 부분 제거
5. 패턴 형성 완료

⚠️ 위험성:
- 피부 및 눈 자극
- 독성 물질 포함 가능
- 빛에 민감함

보관:
- 갈색병 (빛 차단)
- 냉장 보관 (4~8°C)
- 유효기간: 3~6개월
```

#### 2️⃣ 아세톤 (Acetone, C₃H₆O)

```
상태: 액체 (투명)
냄새: 강한 달콤한 냄새

쓰임새:
├─ 포토레지스트 제거 (주 용도)
│  └─ 노광 후 남은 레지스트 완전 제거
├─ 강력한 세정제
│  └─ 기름 및 오염물 제거
└─ 용제

특성:
✓ 높은 휘발성 (빠르게 증발)
✓ 강력한 용매
✓ 저비용

⚠️ 위험성:
- 인화성 (불이 잘 남)
- 높은 독성
- 피부 자극

보관:
- 불에 잘 타므로 특별 관리
- 산소 없는 환경
- 냉침소 권장
```

#### 3️⃣ 메탄올 (Methanol, CH₃OH)

```
상태: 액체 (투명)
냄새: 자극적인 냄새

쓰임새:
├─ 세정제 (아세톤보다 온화)
├─ 포토레지스트 제거 보조제
└─ 용제

특성:
✓ 아세톤보다 온화함
✓ 낮은 휘발성
✓ 저비용

⚠️ 위험성:
- 독성 물질
- 극히 적은 양도 실명 유발 가능
- 피부 흡수 가능

보관:
- 밀폐 용기
- 냉암소 보관
```

#### 4️⃣ 이소프로필알콜 (Isopropyl Alcohol, IPA)

```
상태: 액체 (투명)
냄새: 자극적인 냄새

쓰임새:
├─ 세정제 (가장 일반적)
│  └─ 입자 및 오염물 제거
├─ 건조제
└─ 린스액

특성:
✓ 휘발성 (빠르게 증발)
✓ 수분 흡수성 (건조 용도)
✓ 비교적 안전한 편

⚠️ 위험성:
- 인화성
- 피부 자극
- 눈 손상

보관:
- 불에 잘 타므로 특별 저장
- 냉암소 보관
```

#### 5️⃣ DMSO (Dimethyl Sulfoxide)

```
상태: 액체 (투명)
냄새: 독특한 냄새 (마늘 냄새)

쓰임새:
├─ 용제 (강력함)
├─ 세정
└─ 유기물 제거

특성:
✓ 극도로 강력한 용매
✓ 피부 침투력 높음
✓ 생물학적 활성 높음

⚠️ 위험성:
- 매우 높은 독성
- 피부를 통해 침투 가능
- 생식 독성 가능성

보관:
- 밀폐 용기 (습기 차단)
- 특별 관리 필수
```

#### 6️⃣ 포토이니시에이터 (Photoinitiator)

```
상태: 액체 또는 고체
색상: 황색~갈색

쓰임새:
├─ 포토레지스트의 감광 성분
│  └─ 빛을 화학에너지로 변환
├─ UV 반응 촉발
└─ 패턴 형성 핵심 물질

특성:
✓ 빛에 극히 민감
✓ 화학 반응 개시
✓ 고성능 포토레지스트의 핵심

⚠️ 위험성:
- 독성
- 피부 자극
- 광민성

보관:
- 갈색병 (빛 차단)
- 냉장 보관
```

#### 7️⃣ 크롬산 (Chromic Acid)

```
상태: 액체 또는 고체
색상: 빨간색~오렌지색

쓰임새:
├─ 강력한 산화제 (세정에 사용)
├─ 오염물 제거
└─ 표면 준비

특성:
✓ 극도로 강력한 산화제
✓ 거의 모든 유기물 산화

⚠️ 위험성:
- 극히 위험한 물질
- 발암 물질 (크롬 6가)
- 폐암 유발
- 극심한 화상

보관:
- 특수 용기
- 특별 관리 필수
```

#### 8️⃣ NMP (N-메틸-2-피롤리돈)

```
상태: 액체 (투명)

쓰임새:

✓ 환경에 비교적 친화적

⚠️ 위험성:

```

⚠️ 위험성:
- 매우 높은 독성
- 피부 및 눈 손상

## 📊 4. 공정 단계별 화학물질 사용

### 4.1 포토리소그래피 (Lithography) - 패턴 형성

```
단계 1: 웨이퍼 세정
화학물질:
├─ 황산 (H₂SO₄)
├─ 불산 (HF)
└─ 이소프로필알콜 (IPA)

목적: 표면 완전 청정

단계 2: 포토레지스트 코팅
화학물질:
└─ 포토레지스트

목적: 빛에 반응하는 보호층 형성

단계 3: 자외선 노광
화학물질:
└─ 자외선(UV) 에너지

목적: 포토레지스트 부분 활성화

단계 4: 현상 (Development)
화학물질:
├─ TMAH (알칼리 현상액)
└─ 순수한 물

목적: 반응한 레지스트 제거 → 패턴 형성
```

### 4.2 식각 (Etching) - 물질 깎아내기

```
건식 식각 (Plasma Etching)
화학물질:
├─ 산소 (O₂)
├─ 불소 화합물
└─ 염소 화합물

특징: 매우 정확, 높은 종횡비

습식 식각 (Wet Etching)
화학물질:
├─ 불산 (HF) - 산화층 제거
├─ 인산 (H₃PO₄) - 알루미늄 제거
├─ 염산 (HCl) - 금속 제거
└─ KOH - 실리콘 에칭
```

### 4.3 세정 (Cleaning)

```
입자 제거
화학물질:
├─ 황산 (H₂SO₄)
├─ 과산화수소 (H₂O₂)
└─ 암모니아 (NH₃)

유기물 제거
화학물질:
├─ 아세톤
├─ 메탄올
└─ IPA

메탈 오염물 제거
화학물질:
└─ 여러 산 혼합액
```

### 4.4 산화 (Oxidation) - 절연층 형성

```
열 산화 (Thermal Oxidation)
화학물질:
├─ 산소 (O₂)
├─ 수증기 (H₂O)
└─ 질소 (N₂)

공정:
1. 고온 환경 (700~1200°C)
2. 산소 또는 수증기 통과
3. 웨이퍼 표면에 SiO₂ 형성

결과: 절연층 형성
```

### 4.5 도핑 (Doping) - 불순물 추가

```
p형 도핑 (양공 추가)
도펀트 물질:
├─ 붕소 (B)
├─ 갈륨 (Ga)
└─ 인듐 (In)

n형 도핑 (전자 추가)
도펀트 물질:
├─ 인 (P)
├─ 비소 (As)
└─ 안티몬 (Sb)

주입 방법:
├─ 이온 주입 (고에너지)
├─ 확산 (열 처리)
└─ 증착 (CVD)
```

## 🔐 6. 안전 및 관리

### 6.1 저장 및 취급 방법

```
저장 원칙:
✓ 화학물질별로 분리 저장
✓ 호환성 확인 필수
✓ 용기 밀폐 (증발 방지)
✓ 냉암소 유지
✓ 적절한 온도 (종류별로 다름)

온도 관리:
- 상온 보관: 대부분 무기화학물질
- 냉장 보관 (4~8°C): 포토레지스트
- 냉동 보관 (-20°C): 일부 유기화학물질
- 액화 가스 (-196°C): 액화 암모니아

용기 선택:
- 불산: 특수 고분자만 가능 (금속 절대 불가)
- 강한 산/염기: 강화 플라스틱
- 기타 화학물질: 일반 플라스틱 가능
```

### 6.2 안전 주의사항

```
취급 시 필수 장비:
✓ 안전 고글 (눈 보호)
✓ 화학 방호복 (몸 보호)
✓ 질소 장갑 (손 보호)
✓ 마스크/호흡기 (호흡기 보호)
✓ 안전화 (발 보호)

취급 규칙:
1️⃣ 절대 혼합하지 말 것!
   - 산 + 염기 혼합 금지
   - 서로 다른 산 혼합 금지
   - 폭발 또는 유독 가스 발생

2️⃣ 극도의 주의 (특히 불산)
   - 매우 소량도 치명적
   - 피부 접촉 즉시 응급 처치 필요
   - 호흡 주의

3️⃣ 환기 필수
   - 밀폐 공간 절대 금지
   - 환기 시설 필수
   - 공기 정화 장치 운영

4️⃣ 물 사용 주의
   - 산에 물 추가 금지!
   - 물에 산을 천천히 추가
   - 불산은 물 사용 주의
```

### 6.3 폐기 및 재활용

```
폐기 원칙:
✓ 절대 버리지 말 것 (환경 오염)
✓ 전문 폐기업체에 위탁
✓ 수거 기록 유지

재활용 기회:
- 일부 식각액: 재생 가능
  예: FeCl₃, 일부 산
- 세정액: 필터링으로 재사용 가능

폐기 비용:
- 반도체 공장의 주요 비용 항목
- 일부 사업장: 폐기 비용 > 구매 비용
```

### 6.4 환경 규제

```
한국의 규제:
