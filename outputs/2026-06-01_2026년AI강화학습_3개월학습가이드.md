```

Day 1-2 (3시간): 상태 가치함수 (State Value Function)
- V(s) = 상태 s에서 얻을 수 있는 총 보상의 기댓값

벨만 방정식 (Bellman Equation):
V(s) = E[R_{t+1} + γ·V(s')]

의미:
"현재 상태의 가치 = 즉시 보상 + (할인된 다음 상태의 가치)"

실제 예:
- 로봇이 현재 방에서의 가치
  = 현재 방의 보상 + (다음 방의 가치 × 할인)

Day 3-4 (3시간): 행동 가치함수 (Action Value Function)
- Q(s, a) = 상태 s에서 행동 a를 했을 때의 가치

벨만 방정식:
Q(s, a) = E[R_{t+1} + γ·max Q(s', a')]

차이점:
- V(s): "이 상태는 얼마나 좋은가?"
- Q(s, a): "이 상태에서 이 행동을 하면 얼마나 좋은가?"

Day 5 (2시간): 최적 정책
- 최적 정책 π*(s) = 최고 가치의 행동
- V*(s) = 최적 정책 하에서의 상태 가치
- Q*(s, a) = 최적 정책 하에서의 행동 가치

#### **Week 3: 테이블 기반 강화학습 - Q-Learning**

```
학습 목표:

□ Q-테이블 개념 습득
□ 간단한 환경에서 직접 구현

학습 시간: 11시간 (일일 1.5시간)

학습 내용:

Day 1-2 (3시간): Q-Learning 개념
- Q-Learning이란?
  "경험을 통해 Q(s,a)를 점점 더 정확하게 학습"

Q-러닝 업데이트 식:
Q(s, a) ← Q(s, a) + α·(R + γ·max Q(s', a') - Q(s, a))

의미 분해:
├─ α: 학습률 (새로운 정보를 얼마나 반영할 것인가)
├─ R: 현재 받은 보상
├─ γ·max Q(s', a'): 다음 상태의 예상 가치
└─ Q(s, a)의 오류를 점점 줄여감

Day 3 (2시간): Q-테이블 개념
- 테이블: 모든 (상태, 행동) 쌍의 Q 값 저장
- 예: 격자 세계에서 16 칸 × 4 행동 = 64개 Q 값
- 학습 과정: 테이블 값을 반복해서 업데이트

Day 4 (2시간): 탐색 vs 활용 (Exploration vs Exploitation)
- 딜레마: 알려진 좋은 행동만 할 것 vs 새로운 시도

해결책: ε-Greedy 전략
- 확률 ε로 무작위 행동 (탐색)
- 확률 1-ε로 최고 Q값 행동 (활용)

Day 5 (1시간): SARSA vs Q-Learning
- SARSA: 현재 정책 따라 다음 행동 선택
  SARSA ← Q + α·(R + γ·Q(s', a_selected) - Q)
  
- Q-Learning: 최고 Q값 행동 선택 (다르게)
  Q-Learning ← Q + α·(R + γ·max Q(s', a') - Q)

차이: Q-Learning이 더 효율적

Day 6-7 (3시간): Python으로 직접 구현
```python
# 간단한 Q-Learning 구현 예시
import numpy as np

# Q-테이블 초기화 (상태 수 × 행동 수)
Q = np.zeros((num_states, num_actions))

# 학습 루프
for episode in range(1000):
    state = env.reset()
    
    while not done:
        # ε-Greedy로 행동 선택
        if np.random.random() < epsilon:
            action = np.random.randint(num_actions)  # 탐색
        else:
            action = np.argmax(Q[state, :])  # 활용
        
        # 환경과 상호작용
        next_state, reward, done, _ = env.step(action)
        
        # Q-Learning 업데이트
        Q[state, action] = Q[state, action] + \
            alpha * (reward + gamma * np.max(Q[next_state, :]) - Q[state, action])
        
        state = next_state
```

숙제:
□ Q-Learning 처음부터 직접 구현
□ OpenAI Gym의 "FrozenLake" 환경에서 학습
□ 다양한 학습률(α)과 할인율(γ) 비교 실험
```

학습 시간: 11시간 (일일 1.5시간)

학습 내용:

Day 1-2 (3시간): 정책 기반 방법 왜?
- 테이블 기반의 한계:
  ├─ 상태가 무한하면? (예: 이미지)
  ├─ 연속 상태에서는? (예: 로봇 위치)
  └─ 차원의 저주 (Curse of Dimensionality)

- 해결책: 신경망으로 정책을 표현!
  π(a|s) = 신경망(상태) → 행동의 확률

Day 3 (2시간): 정책 그래디언트 (Policy Gradient)
- 아이디어: 보상이 많은 행동의 확률을 높이자!
- 수식:
  ∇J(θ) ∝ E[∇log π(a|s) · Q(s, a)]

- 의미: 
  "좋은 행동의 log 확률을 높이는 방향으로 가중치 업데이트"

Day 4 (2시간): REINFORCE 알고리즘
- 가장 간단한 정책 그래디언트 방법
- 에피소드 끝까지 경험한 후, 역방향으로 업데이트
- 장점: 간단
- 단점: 분산이 크고 학습 느림

Day 5 (1시간): Actor-Critic 개념
- Actor: 행동 선택 (정책 그래디언트)
- Critic: 선택이 좋은지 평가 (가치함수)
- 함께 학습하면 효율 증가!

Day 6-7 (3시간): 구현 및 실습
```python
# 간단한 Actor-Critic 구현
import torch
import torch.nn as nn

class ActorCritic(nn.Module):
    def __init__(self, state_size, action_size):
        super().__init__()
        
        # Actor (정책) 네트워크
        self.actor = nn.Sequential(
            nn.Linear(state_size, 64),
            nn.ReLU(),
            nn.Linear(64, action_size),
            nn.Softmax(dim=-1)
        )
        
        # Critic (가치) 네트워크
        self.critic = nn.Sequential(
            nn.Linear(state_size, 64),
            nn.ReLU(),
            nn.Linear(64, 1)
        )
    
    def forward(self, state):
        policy = self.actor(state)
        value = self.critic(state)
        return policy, value
```

숙제:
□ REINFORCE 구현 및 실행
□ CartPole 환경에서 정책 그래디언트 학습
□ Actor-Critic 직접 구현
```
