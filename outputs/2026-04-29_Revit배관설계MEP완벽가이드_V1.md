## 1. Revit이란?

### 1.1 Revit 기본 정보

```
프로그램명: Autodesk Revit
개발사: 오토데스크 (Autodesk)
버전: 2024, 2025, 2026 (매년 업데이트)
용도: BIM (Building Information Modeling) 기반 설계
가격: 연간 구독료 약 2,000~3,000 USD (약 250~350만 원)
최적 PC: 고사양 워크스테이션 (16GB RAM 이상)

쉽게 말하면:
CAD (Auto CAD) = 2D 도면 그리기
Revit = 3D 건물 정보 통합 관리 (미래형 설계)
```

## 2. MEP의 개념

### 2.1 MEP란?

```
M.E.P = Mechanical + Electrical + Plumbing

쉽게 말하면: "건물의 몸과 순환계"

┌─────────────────────────────────────────────┐
│         건물의 세 가지 주요 시스템            │
├─────────────────────────────────────────────┤
│                                             │
│ 🔧 Mechanical (기계/냉난방)                │
│    냉방기, 난방기, 환기 시스템              │
│    덕트 (바람 통로), 팬, 필터               │
│    목적: 건물 온도/습도 조절                 │
│    연봉: 약 3,500~5,500만 원              │
│                                             │
│ ⚡ Electrical (전기)                       │
│    발전기, 변압기, 분배반                   │
│    배선, 조명, 콘센트                       │
│    목적: 전력 공급, 조명, 제어              │
│    연봉: 약 4,000~6,000만 원              │
│                                             │
│ 💧 Plumbing (배관/위생)                    │
│    상수도, 하수도, 가스배관                 │
│    화장실, 주방, 스프링클러                 │
│    목적: 물 공급, 오수/우수 처리            │
│    연봉: 약 3,500~5,500만 원  ← 당신!    │
│                                             │
└─────────────────────────────────────────────┘

통합 설계의 중요성:
∴ M + E + P가 충돌 없이 조화 (설계자의 책임)
∴ 한 곳이 바뀌면 다른 곳도 조정 필요
∴ Revit: 자동으로 충돌 감지 & 해결 도움
```

### 2.2 Plumbing (배관 설계)의 중요성

```
배관 설계가 필수인 이유:

1. 생명 유지 기능
   · 깨끗한 물 공급 (상수도)
   · 오염수 제거 (하수도)
   · 응급 상황 대응 (스프링클러)
   → 설계 오류 = 주민 생명 위험

2. 건물 수명에 직결
   · 배관 부식 → 누수 → 건물 손상
   · 올바른 시공 = 건물 30년 이상 지속
   · 설계 불량 = 10년 내 대규모 수리

3. 환경 영향
   · 물 재활용 설계 (절수)
   · 오수 처리 최적화
   · 빗물 활용 시스템
   → 지속 가능 건축의 핵심

4. 비용 영향
   · 배관 = 건설비 10~15%
   · 설계 오류 = 수십억 원 손실
   · 최적화 = 건설비 5~10% 절감

✅ 배관 설계자는 이 모든 책임을 짊어지는 전문가!
```
