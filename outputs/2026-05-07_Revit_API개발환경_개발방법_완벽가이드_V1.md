## 1. Revit API 소개

### 1.1 Revit API란?

Revit API는 Autodesk Revit의 기능을 확장하기 위한 공식 개발 인터페이스입니다. 개발자는 이를 통해 Revit의 기본 기능을 넘어서는 고도의 자동화, 데이터 처리, 사용자 정의 기능을 구현할 수 있습니다.

### 1.2 Revit API의 특징

- **1,700개 이상의 클래스**: 건축 설계, MEP 설계, 구조 설계 등 다양한 분야를 지원
- **50개 이상의 인터페이스**: 확장성과 유연성 제공
- **500개 이상의 열거형(Enumeration)**: 다양한 옵션 및 설정 제공
- **완전한 문서화**: 공식 문서와 API 참고서 제공
- **크로스 플랫폼 지원**: Windows, Mac 환경에서 작동

### 1.3 Revit API로 할 수 있는 작업

```
✓ BIM 모델에서 요소(Element) 생성, 수정, 삭제
✓ 매개변수(Parameter) 자동 입력 및 추출
✓ 도면 및 뷰 자동 생성
✓ 스케줄 및 범례 작성
✓ MEP 설비 자동 배치
✓ 구조 철근 자동 배치
✓ 데이터 내보내기 (IFC, DWG, PDF 등)
✓ 외부 시스템과 연동 (ERP, CAD 소프트웨어, 데이터베이스)
✓ 사용자 정의 도구 및 플러그인 개발
✓ 배치 처리 및 자동화
```

## 2. Revit API 구조

### 2.1 핵심 어셈블리(Assembly)

Revit API는 두 개의 주요 DLL 파일로 구성됩니다:

#### **RevitAPI.dll**
- Revit의 핵심 기능을 다루는 클래스 제공
- 모델 요소, 매개변수, 기하학(Geometry) 처리
- 데이터베이스 쿼리 및 필터링
- 위치 정보(Location), 방향(Orientation) 처리
- 주요 네임스페이스:
  - `Autodesk.Revit.DB` - 기본 데이터 베이스 기능
  - `Autodesk.Revit.DB.Geometry` - 기하학 정보 처리

#### **RevitAPIUI.dll**
- Revit의 사용자 인터페이스 제어
- 이벤트 처리
- 외부 명령(External Command) 구현
- 주요 네임스페이스:
  - `Autodesk.Revit.UI` - UI 제어
  - `Autodesk.Revit.UI.Events` - 이벤트 처리

### 2.2 주요 네임스페이스

| 네임스페이스 | 설명 | 주요 클래스 |
|---------|------|---------|
| `Autodesk.Revit.DB` | 데이터베이스 기능 | Document, Element, Parameter |
| `Autodesk.Revit.DB.Architecture` | 건축 설계 | Wall, Floor, Roof, Door, Window |
| `Autodesk.Revit.DB.MEP` | MEP 설비 | Duct, Pipe, Connector |
| `Autodesk.Revit.DB.Structure` | 구조 설계 | AnalyticalModel, Reinforcement |
| `Autodesk.Revit.UI` | 사용자 인터페이스 | UIApplication, UIDocument |
| `Autodesk.Revit.UI.Events` | 이벤트 | DocumentOpenedEvent, ElementsDeletedEvent |

### 2.3 API 버전 관리

```
Revit 2024: .NET Framework 4.7.2
Revit 2025: .NET Framework 4.8 / .NET 8 Preview
Revit 2026: .NET 8 Full Support
```

각 Revit 버전은 특정 .NET Framework 버전을 요구합니다. 하위 호환성을 제공하지만, 최신 기능을 사용하려면 최신 .NET Framework가 필요합니다.

## 5. C# 애드인 개발

### 5.1 기본 애드인 구조

```csharp
// 1단계: 필요한 라이브러리 import
using Autodesk.Revit.Attributes;  // 애드인 속성
using Autodesk.Revit.DB;          // 데이터베이스 기능
using Autodesk.Revit.UI;          // UI 기능

// 2단계: IExternalCommand 인터페이스 구현
[Transaction(TransactionMode.Manual)]
[Regeneration(RegenerationOption.Manual)]
public class HelloRevitCommand : IExternalCommand
{
    // 3단계: Execute 메서드 구현
    public Result Execute(
        ExternalCommandData commandData,
        string message,
        ElementSet elements)
    {
        try
        {
            // UIApplication 객체에서 현재 Revit 애플리케이션 정보 얻기
            UIApplication uiApp = commandData.Application;
            Document doc = uiApp.ActiveUIDocument.Document;
            
            // Transaction 시작 (Revit 모델 변경 시 필수)
            using (Transaction trans = new Transaction(doc))
            {
                trans.Start("Create Wall");
                
                // 여기서 Revit 모델 변경 작업 수행
                TaskDialog.Show("Revit", "Hello Revit!");
                
                trans.Commit();
            }
            
            return Result.Succeeded;
        }
        catch (Exception ex)
        {
            message = ex.Message;
            return Result.Failed;
        }
    }
}

// 4단계: ExternalApplication 인터페이스 구현 (옵션)
public class HelloRevitApp : IExternalApplication
{
    // 애드인 시작 시 실행
    public Result OnStartup(UIControlledApplication application)
    {
        TaskDialog.Show("StartUp", "Addin Loaded!");
        return Result.Succeeded;
    }
    
    // 애드인 종료 시 실행
    public Result OnShutdown(UIControlledApplication application)
    {
        TaskDialog.Show("ShutDown", "Addin Unloaded!");
        return Result.Succeeded;
    }
}
```

### 5.2 주요 Attributes (속성)

```csharp
// Transaction 속성 - 데이터베이스 변경 작업
[Transaction(TransactionMode.Manual)]    // 수동으로 관리
[Transaction(TransactionMode.Automatic)] // 자동 커밋

// Regeneration 속성 - 모델 재생성
[Regeneration(RegenerationOption.Manual)]   // 수동 재생성
[Regeneration(RegenerationOption.Automatic)] // 자동 재생성

// Journaling 속성 - 매크로 기록 지원
[Journaling(JournalingMode.UsingCommandData)]
```

### 5.3 실제 코드 예제: 모든 벽 목록 출력

```csharp
[Transaction(TransactionMode.ReadOnly)]
public class ListWallsCommand : IExternalCommand
{
    public Result Execute(ExternalCommandData commandData, 
        string message, ElementSet elements)
    {
        try
        {
            Document doc = commandData.Application.ActiveUIDocument.Document;
            
            // FilteredElementCollector: 특정 요소만 효율적으로 선택
            FilteredElementCollector collector = 
                new FilteredElementCollector(doc);
            
            // Wall 타입의 모든 요소 선택
            ICollection<Element> walls = 
                collector.OfClass(typeof(Wall)).ToElements();
            
            // 결과 표시
            string message_text = $"총 {walls.Count}개의 벽이 있습니다.\n\n";
            foreach (Element wall in walls)
            {
                message_text += $"벽 이름: {wall.Name}\n";
            }
            
            TaskDialog.Show("Revit", message_text);
            return Result.Succeeded;
        }
        catch (Exception ex)
        {
            TaskDialog.Show("Error", ex.Message);
            return Result.Failed;
        }
    }
}
```

## 6. Python/PyRevit 개발

### 6.1 PyRevit 스크립트 기본 구조

PyRevit 스크립트는 다음과 같은 구조를 가집니다:

```python
# -*- coding: utf-8 -*-
# PyRevit 내장 객체:
# __revit__: Revit 애플리케이션 객체
# __doc__: 스크립트 설명
# uidoc: UIDocument (현재 프로젝트)
# doc: Document (Revit 모델)

from Autodesk.Revit.DB import *
from Autodesk.Revit.UI import TaskDialog

# 현재 프로젝트 문서 객체 얻기
doc = __revit__.ActiveUIDocument.Document

# 메시지 출력
print("PyRevit 스크립트 시작")

# Revit 다이얼로그 출력
TaskDialog.Show("PyRevit", "Hello from Python!")

# 변경사항 저장이 필요하면 Transaction 사용
with Transaction(doc, "작업 이름") as trans:
    trans.Start()
    # 변경 작업 수행
    trans.Commit()

print("작업 완료")
```

### 6.2 PyRevit에서 모든 벽 목록 출력

```python
# -*- coding: utf-8 -*-
# 모든 벽의 정보를 출력하는 PyRevit 스크립트

from Autodesk.Revit.DB import *

doc = __revit__.ActiveUIDocument.Document

# 모든 Wall 요소 필터링
walls = FilteredElementCollector(doc).OfClass(Wall).ToElements()

# 결과 출력
print(f"총 {len(walls)}개의 벽이 있습니다.\n")
for wall in walls:
    wall_type = wall.WallType.Name if wall.WallType else "없음"
    print(f"벽 이름: {wall.Name}")
    print(f"벽 타입: {wall_type}")
    print(f"----")
```

### 6.3 PyRevit 개발 팁

```
✓ 스크립트는 __file__ 위치의 폴더에 저장해야 자동 로드됨
✓ Python 문법 오류는 Revit 내 콘솔에서 즉시 확인 가능
✓ print()는 Revit의 Output 콘솔에 출력됨
✓ IronPython 사용 (CPython이 아님) - 라이브러리 호환성 확인 필요
✓ 디버깅은 print()문과 Output 창 활용
```

### 8.2 Element 클래스 (모든 Revit 객체의 기본)

```csharp
// 벽, 문, 창, 기둥 등 Revit의 모든 객체는 Element의 서브클래스

Element element;  // 임의의 요소

// 요소 정보 조회
string elementName = element.Name;
ElementId elementId = element.Id;
ElementId typeId = element.GetTypeId();

Category category = element.Category;
```

### 8.3 Parameter 클래스 (매개변수 처리)

```csharp
// 매개변수는 요소의 속성을 저장하는 저장소

Element wall;  // 벽 요소라고 가정

// 매개변수 값 읽기
Parameter heightParam = wall.LookupParameter("높이");
if (heightParam != null)
{
    string value = heightParam.AsString();      // 문자열로 읽기
    double numValue = heightParam.AsDouble();   // 숫자로 읽기
    int intValue = heightParam.AsInteger();     // 정수로 읽기
}

// 매개변수 값 쓰기
Parameter markParam = wall.LookupParameter("표기");
if (markParam != null && !markParam.IsReadOnly)
{
    markParam.Set("A-101");  // 값 설정
}

// 모든 매개변수 순회
ParameterSet paramSet = wall.Parameters;
foreach (Parameter param in paramSet)
{
    string paramName = param.Definition.Name;
    string paramValue = param.AsString();
}
```

### 8.4 FilteredElementCollector (요소 선택)

```csharp
// 효율적인 요소 선택 도구

Document doc;
FilteredElementCollector collector = 
    new FilteredElementCollector(doc);

// 1. 특정 클래스의 모든 요소 선택
ICollection<Element> allWalls = 
    collector.OfClass(typeof(Wall)).ToElements();

// 2. 특정 카테고리의 요소 선택
collector = new FilteredElementCollector(doc);
ICollection<Element> doors = 
    collector.OfCategory(BuiltInCategory.OST_Doors).ToElements();

// 3. 특정 타입의 요소만 선택
collector = new FilteredElementCollector(doc);
ElementTypeFilter filter = new ElementTypeFilter(typeof(WallType));
ICollection<Element> wallTypes = 
    collector.WherePasses(filter).ToElements();

// 4. 커스텀 필터 조합
collector = new FilteredElementCollector(doc);
ElementClassFilter classFilter = 
    new ElementClassFilter(typeof(Wall));
ElementCategoryFilter categoryFilter = 
    new ElementCategoryFilter(BuiltInCategory.OST_Walls);
LogicalAndFilter logicalFilter = 
    new LogicalAndFilter(classFilter, categoryFilter);
ICollection<Element> filteredWalls = 
    collector.WherePasses(logicalFilter).ToElements();
```

### 8.5 Transaction (데이터베이스 변경)

```csharp
// Revit 데이터베이스 변경 시 필수

Document doc;

// 1. 기본 Transaction
using (Transaction trans = new Transaction(doc))
{
    trans.Start("벽 생성");
    
    // 변경 작업 수행
    // ... 벽 생성 코드 ...
    
    trans.Commit();
}

// 2. 변경사항 되돌리기
using (Transaction trans = new Transaction(doc))
{
    trans.Start("실험적 작업");
    try
    {
        // ... 작업 ...
        trans.Commit();
    }
    catch (Exception ex)
    {
        trans.RollBack();  // 변경사항 취소
    }
}

    new TransactionGroup(doc, "복합 작업"))
{
    transGroup.Start();
    
    using (Transaction trans1 = new Transaction(doc))
    {
        trans1.Start("작업 1");
        // ... 작업 1 ...
        trans1.Commit();
    }
    
    using (Transaction trans2 = new Transaction(doc))
    {
        trans2.Start("작업 2");
        // ... 작업 2 ...
        trans2.Commit();
    }
    
    transGroup.Assimilate();
}
```
