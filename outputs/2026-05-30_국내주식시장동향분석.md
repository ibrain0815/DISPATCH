## 👤 6. 개인투자자 가이드

### 6.1 투자 관점에서 지금이 좋은가?

```
시각 1 - 낙관론:
"AI 붐은 아직 초기 단계"
→ 앞으로 더 상승할 가능성

시각 2 - 조심론:
"이미 많이 올랐음"
→ 조정 위험 존재

균형잡힌 접근:
1. 일부는 매수 (긍정적 기업)
2. 일부는 현금 보유 (조정 대비)
3. 분할 매수 활용
```

### 6.2 초보자 추천 전략

```
포트폴리오:
├─ 30%: 안정적 우량주 (삼성전자, SK하이닉스)
├─ 30%: 채권/채권펀드 (안정성)
├─ 20%: 성장주/기술주 (수익률)
└─ 20%: 현금 (기회 대비)
```

### 6.3 주의할 점

```
⚠️ 주의 사항:
1. 투기성 거래 피하기
   - 급등한 주식 후려매기 위험 높음
   
2. 분할 매수 실천
   - 한 번에 다 사지 말 것
   
3. 손절 규칙 정하기
   - 하락 시 10~15% 손실 정해두기
   
4. 장기 관점 유지
   - 단기 변동에 흔들리지 않기
```
